# 08 状语从句与连词

> **大纲依据**：《成人高等教育本科生学士学位英语水平考试大纲（非英语专业）》（四）语法第 7 条要求“掌握基本的英语语法知识……各类从句的构成及其用法”；第 4 条要求掌握“常用连接词……的词义及其用法”。状语从句连接词的选择（时间、条件、让步、结果、目的、方式）正是这两条大纲要求的直接落点。
> **真题分布**：《成人高等教育学士学位英语考试历年真题+标准题库》（2013 版）收录的 10 套真题（下称“《题库》10 套真题”或“原书”）中共考查 7 题（真题（二）第42题，真题（四）第39、49题，真题（七）第47题，真题（八）第33、48题，真题（九）第42题），占 Part III 词汇语法总题量的 3.5%（7/200）。

## 一、考点定位：为什么这样考

状语从句在 Part III 中的考查方式分为两类：一是**题干留出连词空位，四个选项为语义或词性各异的连词与短语**，要求根据主从句之间的逻辑关系（时间、让步、结果、目的、方式）及句法功能锁定答案；二是**题干已给出连接词，四个选项为同一从句的不同语序或时态形式**，要求考生掌握“状语从句一律用陈述语序”以及“时间、条件、让步状语从句用一般现在时表将来（主将从现）”的硬性规则。《题库》10 套真题的 200 道词汇语法题中，状语从句与连词共考查 7 题，占比 3.5%，是三类从句考点中题量最多的类别。

7 道真题的逻辑类型分布如下：

| 逻辑类型 | 题号 | 答案 |
|---|---|---|
| 方式（`as if`） | 真题（二）第42题 | as if |
| 结果（`such … that`） | 真题（四）第39题 | that |
| 让步（`whether … or not`） | 真题（四）第49题 | Whether you like it |
| 让步（`however much`） | 真题（七）第47题 | the dictionary costs |
| 目的（`so that` + 情态动词） | 真题（八）第33题 | could |
| 时间（`the instant`） | 真题（八）第48题 | the instant（原书答案 in an instant 存疑） |
| 时间（`the moment`） | 真题（九）第42题 | the moment |

命题人设置干扰项的三类固定套路：

1. **同形近义短语混排**：将 `as regards` / `as to` / `as for` / `as if` 并列排布，利用前缀相同混淆介词短语与从属连词（真题（二）第42题）。
2. **语序与时态双重陷阱**：在让步状语从句选项中设置疑问语序（`does the dictionary cost`）或将来时态（`will cost`）（真题（七）第47题）。
3. **介词短语冒充从属连词**：`in an instant` / `for an instant` 仅能在单句内部充当时间状语，不具备连接从句的语法功能，却被置于需要从属连词的位置作干扰（真题（八）第48题）。

## 二、核心规则

### 1. 引导状语从句的常用连词一览

| 逻辑关系 | 常用连接词 | 例句 |
|---|---|---|
| 时间 | `when` / `while` / `as` / `before` / `after` / `since` / `until` / `till` / `once` / `as soon as`；名词性连接词 `the moment` / `the instant` / `the minute` / `the second`；副词性连接词 `immediately` / `directly` / `instantly` | We left as soon as the rain stopped. |
| 条件 | `if` / `unless` / `as long as` / `so long as` / `in case` / `provided (that)` / `on condition that` | You will fail unless you work harder. |
| 让步 | `although` / `though` / `even if` / `even though` / `no matter how (what, who…)` / `however` / `whatever` / `whoever` / `whether … or not` | Although it was late, he kept working. |
| 结果 | `so` + adj./adv. + `that`；`such` (+ `a/an` + adj.) + n. + `that` | It was so hot that we stayed indoors. |
| 目的 | `so that` / `in order that` + 从句；`so as to` / `in order to` + 动词原形 | She spoke slowly so that we could follow her. |
| 方式/比较 | `as if` / `as though`；`as`；`than` | She acted as if nothing had happened. |

### 2. 时间状语从句

- **“一……就……”的五类连接结构**：① 从属连词 `as soon as`；② 名词短语作连接词 `the moment / the instant / the minute / the second (that) + 陈述句`；③ 副词作连接词 `immediately / directly / instantly + 陈述句`；④ `hardly / scarcely … when …`；⑤ `no sooner … than …`（第④、⑤类主句若将否定词置于句首，主句必须用过去完成时且部分倒装，从句用一般过去时）。如：`Hardly had I sat down when the phone rang.`
- **`while` 与 `the moment` 的硬性区分**：`while` 表“在……期间”引导时间状语从句时，表示持续性背景动作，从句谓语**必须是延续性动词或进行时态**，绝不能接瞬间动词；`the moment` / `the instant` 表示“一……就……”，强调两个动作紧接着发生，从句谓语为**瞬间性（非延续性）动词**。如：`While I was cooking, the phone rang.`
- **主将从现规则**：当主句为将来时态（`will/shall do`、`be going to do`）、祈使句或含情态动词表将来意义时，时间、条件、让步状语从句的谓语动词**一律用一般现在时表示将来动作**，严禁在从句中使用 `will/shall + 动词原形`。如：`If it rains tomorrow, we will stay at home.`

### 3. 让步状语从句

- `however + 形容词/副词 + 主语 + 谓语` = `no matter how + 形容词/副词 + 主语 + 谓语`，从句**一律使用陈述语序**（主语在前、谓语在后），严禁使用疑问倒装语序。如：`However cold it is, he swims every day.`
- `no matter what / who / where / when` = `whatever / whoever / wherever / whenever`（引导让步状语从句时二者完全等价；若引导名词性从句则只能用后者）。如：`Whatever you say, I will not change my mind.`
- `whether … or not` 引导让步状语从句，意为“无论……与否”，从句**一律使用陈述语序**，且不能用 `if` 替换 `whether`。如：`Whether you agree or not, I will keep trying.`
- `as` / `though` 引导让步状语从句时，可将表语、状语或动词原形提到从句句首构成部分倒装（`as` 必须倒装，`though` 可倒装也可不倒装，`although` 绝不能倒装）。如：`Young as she is, she is very brave.`

### 4. 结果状语从句：`so … that` 与 `such … that`

| 结构 | 适用条件与构成公式 | 例 |
|---|---|---|
| `so … that` | 中心词为形容词或副词（无名词）：`so` + 形容词/副词 + `that` | It is `so` difficult `that` no one can solve it. |
| `so … that` | 中心词为可数名词单数：`so` + 形容词 + `a/an` + 单数可数名词 + `that` | `It was so hot a day that we stayed indoors.` |
| `such … that` | 中心词为可数名词单数：`such` + `a/an` + 形容词 + 单数可数名词 + `that` | `It was such a good film that I saw it twice.` |
| `such … that` | 中心词为可数名词复数或不可数名词：`such` + 形容词 + 复数/不可数名词 + `that` | `They were such difficult problems that nobody solved them.` |
| `so … that` | 名词前有表示数量多少的 `many / much / few / little` 时：**一律用 `so`**（仅当 `little` 表“小的”修饰可数名词时才用 `such`） | `There were so many people that we couldn't get in.` |

### 5. 目的状语从句

- `so that` / `in order that` 引导目的状语从句，由于目的在主句动作发生时属于尚未实现的意向，从句谓语必须由“**情态动词 + 动词原形**”构成：主句为现在时或将来时，从句用 `can` / `may` / `will`；主句为一般过去时，从句受时态呼应限制一律改用过去式情态动词 `could`（表能力或客观可能性）、`might`（表轻微可能性）或 `would`（表意愿）。如：`She locked the door so that nobody could enter.`
- `so as to` / `in order to` 是不定式短语，其后只能接**动词原形**作目的状语，绝不能接完整从句。如：`She whispered so as not to wake the baby.`
- 区分 `so that`（引导目的状语从句时两词紧邻，其后直接跟含情态动词的从句；注：`so that` 紧邻时亦可引导结果状语从句，但此时从句一般不带表目的的情态动词）与 `so … that`（表结果，`so` 与 `that` 之间必须夹有形容词或副词）。如：`He spoke so fast that nobody understood him.`

### 6. 方式状语从句与 `as` 短语辨析

- `as if` / `as though` 是从属连词，意为“仿佛、好像”，其后可接四类结构：① 完整从句（若从句所述与客观事实相反，必须用虚拟语气；若所述极可能为客观事实，则用陈述语气）；② 动词不定式（`as if to do`，表“好像要去做某事”）；③ 分词短语（主语与分词存在主动关系用现在分词，被动关系用过去分词）；④ 形容词或介词短语（省略了 `主语 + be`）。如：`He talks as if he knew everything.`
- 形近短语辨析：`as regards`、`as to`、`as for` 均为复合介词，意为“关于、至于”，其后**只能接名词、代词或动名词作宾语**，不能接从句或动词不定式；`as if` 为连词，后接从句或非谓语结构。如：`As for me, I prefer coffee.`

## 三、真题精解

### 真题（二）第42题

- **题干/选项**：When Tom was about to speak, his father looked at him, ________ to stop him.
  - A. as regards　B. as to　C. as for　D. as if
- **答案**：D
- **译文**：当汤姆要说话的时候，他爸爸看着他，好像要制止他一样。
- **解题思路**：
  1. **定位题干信号**：逗号前 `his father looked at him` 是主干完整的句子，空格后是动词不定式短语 `to stop him`。
  2. **套用核心规则**：空格处需要填入一个能够直接搭配动词不定式（构成省略式方式状语从句）的连词。`as if` 后接不定式 `to do`（即 `as if he wanted to stop him` 的省略形式）是固定语法结构，表示“仿佛要……、好像要……”。
  3. **得出唯一答案**：A、B、C 三项均为复合介词，后面只能接名词或动名词，不能接不定式 `to stop him`；只有 D 项 `as if` 符合语法结构与“好像要制止他”的语境，故选 D。
- **干扰项分析**：
  - A. `as regards`：复合介词，意为“关于、至于”，后接名词或动名词，不能接动词不定式。
  - B. `as to`：复合介词，意为“至于、关于”，只接名词性成分或“疑问词 + 不定式”，不能直接接不定式表方式。
  - C. `as for`：复合介词，意为“至于、就……而言”，用于句首转换话题且后接名词或代词，不能接不定式。
- **举一反三**：牢记 `as if / as though` 的四类常考后续结构：`He opened his mouth as if to say something.`（+ 不定式，表“好像要……”）/ `He looks as if he were ill.`（+ 虚拟语气从句，与事实相反）/ `He stared at me as if seeing a ghost.`（+ 现在分词）/ `He stood there as if dead.`（+ 形容词）。

### 真题（四）第39题

- **题干/选项**：It's such a difficult problem ________ no one can work it out.
  - A. as　B. that　C. so　D. thus
- **答案**：B
- **译文**：这个问题如此之难，没人可以解决。
- **解题思路**：
  1. **定位题干信号**：主句包含 `such + a + 形容词 (difficult) + 单数可数名词 (problem)`，空格后 `no one can work it out` 是主语（`no one`）、谓语（`can work`）、宾语（`it`）齐全的完整分句。
  2. **套用核心规则**：当主句出现 `such (+ a/an + adj.) + n.`，且后接成分完整的从句表示“如此……以至于……”时，属于结果状语从句，固定使用连词 `that`。
  3. **得出唯一答案**：空格后从句不缺任何主干成分，排除引导定语从句的 `as`，唯一能构成 `such … that …` 结果状语从句的是 B 项 `that`，故选 B。
- **干扰项分析**：
  - A. `as`：`such … as` 引导定语从句时，`as` 必须在从句中充当主语或宾语（即从句必须缺成分）；本题从句 `no one can work it out` 中 `work out` 已有宾语 `it`，成分完整，故不能用 `as`（若去掉 `it`，写成 `such a difficult problem as no one can work out`，才选 `as`）。
  - C. `so`：`so` 是副词，不能引导结果状语从句。
  - D. `thus`：`thus` 是副词，意为“因此”，不能充当连词连接从句。
- **举一反三**：区分 `such … that`（结果状语从句，从句成分完整）与 `such … as`（定语从句，从句缺主语或宾语）：`It is such a heavy box that nobody can lift it.`（有宾语 `it` → 结果从句用 `that`）/ `It is such a heavy box as nobody can lift.`（缺 `lift` 的宾语 → 定语从句用 `as`）。

### 真题（四）第49题

- **题干/选项**：________ or not, you are going to face him one day.
  - A. If you like it　B. Whether you like it　C. However you like it　D. Whether do you like it
- **答案**：B
- **译文**：无论你喜不喜欢，总有一天要面对他。
- **解题思路**：
  1. **定位题干信号**：空格位于句首，紧跟 `or not`，逗号后为主句 `you are going to face him one day`，前后呈让步关系“不管……与否，都……”。
  2. **套用核心规则**：与 `or not` 直接搭配引导让步状语从句的连词只能是 `whether`（构成 `whether … or not` 固定结构），且所有状语从句内部必须采用**陈述语序**（主语 + 谓语）。
  3. **得出唯一答案**：同时满足“连词用 `whether`”与“陈述语序 `you like it`”的只有 B 项 `Whether you like it`，故选 B。
- **干扰项分析**：
  - A. `If you like it`：`if` 只能引导条件状语从句（“如果”），不能与 `or not` 搭配引导让步状语从句。
  - C. `However you like it`：`however` 引导让步状语从句时意为“无论多么……”，其后必须紧接被修饰的形容词或副词（如 `However much you like it`），不能直接接主谓结构，且不与 `or not` 搭配。
  - D. `Whether do you like it`：误用了助动词提前的疑问语序 `do you like it`，违反了状语从句一律用陈述语序的规则。
- **举一反三**：`whether … or not`、`whether or not …`、`whether A or B` 均可引导让步状语从句，从句一律用陈述语序且一般现在时表将来：`Whether rich or poor, she loves him.` / `Whether or not it rains, we'll go.`

### 真题（七）第47题

- **题干/选项**：However much ________, it will be worth the money.
  - A. the dictionary costs　B. costs the dictionary　C. the dictionary will cost　D. does the dictionary cost
- **答案**：A
- **译文**：不管这本词典花多少钱，它都是物有所值。
- **解题思路**：
  1. **定位题干信号**：句首 `However much`（相当于 `No matter how much`）引导让步状语从句，主句 `it will be worth the money` 为一般将来时。
  2. **套用核心规则**：第一，`however + 形容词/副词` 引导让步状语从句时，其后必须采用**陈述语序**（`主语 + 谓语`）；第二，根据“**主将从现**”规则，主句为一般将来时（`will be`），让步状语从句必须用**一般现在时**表示将来。
  3. **得出唯一答案**：主语 `the dictionary` 为第三人称单数，一般现在时陈述语序为 `the dictionary costs`，故选 A。
- **干扰项分析**：
  - B. `costs the dictionary`：将谓语动词置于主语之前，语序错误。
  - C. `the dictionary will cost`：语序虽为陈述语序，但在让步状语从句中误用了将来时 `will cost`，违反“主将从现”规则。
  - D. `does the dictionary cost`：误用了一般疑问句语序。
- **举一反三**：`however` 与 `no matter how` 引导让步状语从句时完全等价，谨记两条铁律——“陈述语序 + 一般现在时表将来”：`However hard he tries, he can't win.` / `No matter how late it is, she keeps working.`

### 真题（八）第33题

- **题干/选项**：I wrote down the number so that I ________ remember it.
  - A. might　B. should　C. could　D. needed
- **答案**：C
- **译文**：我写下了号码，以便能记住它。
- **解题思路**：
  1. **定位题干信号**：连词 `so that` 引导目的状语从句，主句谓语动词 `wrote` 为一般过去时，从句谓语为“情态动词 + `remember`”。
  2. **套用核心规则**：`so that` 引导的目的状语从句中，主句为过去时，从句情态动词须用过去式；当句意表达“为了**能够**做成某事（具备记住号码的能力或条件）”时，固定选用 `could`。
  3. **得出唯一答案**：记下号码的目的是让自己“能够”记住它，强调能力得以实现，故选 C 项 `could`。
- **干扰项分析**：
  - A. `might`：侧重微弱的主观推测（“或许、万一”），多用于防范性或不确定性极高的语境，不如表“能够”的 `could` 贴合“写下号码以便记住”的明确目的。
  - B. `should`：意为“应该”或用于 `lest / in case / for fear that` 引导的从句中表“以免”，在肯定目的句中不表“能够”。
  - D. `needed`：`need` 作情态动词时无过去式且仅用于否定句和疑问句；作实义动词过去式 `needed` 时后须接 `to remember`，不能直接接动词原形 `remember`。
- **举一反三**：严格区分 `so that`（表目的，后接含情态动词 `can/could/may/might` 的从句）与 `so … that`（表结果，`so` 后紧接形容词或副词）：`He got up early so that he could catch the bus.` / `He got up so early that he caught the bus.`

### 真题（八）第48题

- **题干/选项**：You see the lightning ________ it happens, but you hear the thunder later.
  - A. the instant　B. for an instant　C. on the instant　D. in an instant
- **答案**：D（原书答案；本题语法存疑，见下）
- **译文**：闪电发生后，你可以马上看到，但是稍后才能听到雷声。
- **解题思路**：
  1. **定位题干信号**：空格前 `You see the lightning` 与空格后 `it happens` 均为主谓完整的独立分句，中间无任何标点或其他连词。
  2. **套用核心规则**：两个完整主谓结构之间**必须由连词连接**。表示“一……就……”的名词短语 `the instant`、`the moment`、`the minute` 可直接充当从属连词引导时间状语从句（相当于 `as soon as`），而一切“介词 + 名词”构成的介词短语（如 `for an instant`、`on the instant`、`in an instant`）只能作单句内部的状语，绝无连接从句的语法功能。
  3. **得出唯一答案**：依标准英语语法，此处唯一能连接从句 `it happens` 的是从属连词 `the instant`（选 A，即 `You see the lightning the instant it happens`“闪电一发生你就能看到它”）；原书参考答案误将介词短语 D 项 `in an instant` 当作连词。
- **干扰项分析**：
  - A. `the instant`：名词短语作从属连词，意为“一……就……”，引导时间状语从句 `it happens`，是符合标准语法的唯一正确选项。
  - B. `for an instant`：介词短语，意为“持续了一瞬间”，只能作状语，不能引导从句。
  - C. `on the instant`：介词短语，意为“立即”，只能作状语，不能引导从句。
  - D. `in an instant`：介词短语，意为“立刻、马上”，只能作状语，无法连接后面的从句 `it happens`（原书误选此项）。
- **举一反三**：熟练掌握“一……就……”引导时间状语从句的名词性连词家族：`the instant`、`the moment`、`the minute`、`the second`，它们后面直接接陈述句，前面**绝不加任何介词**。一旦加上介词（如 `in an instant`、`for a moment`、`at the moment`），就变成了介词短语，不能再接从句。

> **存疑**：**原书参考答案**：D（核对原书答案时以此为准）；**考场作答建议**：选 A（标准语法依据为：空格前后 `You see the lightning` 与 `it happens` 均为完整主谓结构，中间必须填入从属连词；A 项 `the instant` 可作从属连词引导时间状语从句，意为“一……就……”；而 D 项 `in an instant` 为介词短语，仅能作状语，不具备连接从句的语法功能，原书答案有误）。

### 真题（九）第42题

- **题干/选项**：I was so familiar with her that I recognized her voice ________ I picked up the phone.
  - A. the moment　B. since　C. before　D. while
- **答案**：A
- **译文**：我和她太熟了，以至于我一接起电话就能辨认出她的声音。
- **解题思路**：
  1. **定位题干信号**：`that` 引导的结果状语从句内部包含两个分句：`I recognized her voice`（认出她的声音）与 `I picked up the phone`（拿起电话），两个动作均为**瞬间性（非延续性）动作**。
  2. **套用核心规则**：前半句铺垫“我和她非常熟悉”，逻辑上应是“一拿起电话的瞬间就认出了声音”。表示两个瞬间动作紧接着发生（“一……就……”），应使用名词性从属连词 `the moment`。
  3. **得出唯一答案**：只有 A 项 `the moment`（相当于 `as soon as`）能搭配瞬间动词 `picked up` 并表达“一……就……”的时间关系，故选 A。
- **干扰项分析**：
  - B. `since`：意为“自从……以来”，要求主句使用完成时态（`have/had recognized`），而题干主句为一般过去时 `recognized`，且语义不合。
  - C. `before`：意为“在……之前”，“还没接起电话就认出电话里的声音”违背常理。
  - D. `while`：意为“在……期间”，从句谓语必须是延续性动词或进行时态，不能搭配瞬间动作 `picked up the phone`。
- **举一反三**：严守“瞬间 vs 持续”的动词搭配界限：`while` 只能搭配延续性动词或进行时（如 `while I was reading`）；`the moment` / `the instant` / `as soon as` 搭配瞬间动词表示“一……就……”（如 `the moment I saw him`）。

## 四、易错点与陷阱清单

| 陷阱 | 表现 | 破解 |
|---|---|---|
| 形近短语混排 | 把复合介词 `as regards` / `as to` / `as for` 当成连词 `as if` | 看空格后成分：接名词/代词用复合介词，接从句/不定式/分词用 `as if` |
| 连词与介词短语混淆 | 在两个完整分句之间填 `in an instant` / `for a moment` | 连接从句必须用从属连词 `the instant` / `the moment`，前面绝不加介词 |
| 语序陷阱 | 在 `however` / `whether` 让步从句中选疑问语序（`does it cost`） | 所有状语从句内部一律使用“主语 + 谓语”的陈述语序 |
| 时态陷阱 | 在时间、条件、让步状语从句中选 `will do` | 遵循“主将从现”，主句表将来时，从句一律用一般现在时 |
| `so` 与 `such` 误用 | 写出 `so a difficult problem` 或 `such many people` | 单数可数名词用 `such a + adj. + n.` 或 `so + adj. + a + n.`；有 `many/much/few/little`（表数量）一律用 `so` |
| `so that` 与 `so … that` 混淆 | 把目的状语从句与结果状语从句混用 | `so that` 紧邻表目的（后接情态动词从句）；`so … that` 中间夹形容词/副词表结果 |
| `while` 与 `the moment` 误用 | 在瞬间动词前误用 `while` | `while` 只配延续性动词或进行时；瞬间动作表“一……就……”用 `the moment` / `the instant` |
| `if` 冒充 `whether` | 写出 `If you like it or not` | 与 `or not` 搭配引导让步状语从句只能用 `whether`，绝不能用 `if` |

## 五、自测（举一反三）

1. ________ he comes, I will tell him the news.
   A. While　B. The moment　C. Since　D. Until
2. It was ________ a cold day that we stayed at home.
   A. so　B. such　C. very　D. too
3. She had hardly arrived ________ it began to rain.
   A. than　B. when　C. while　D. since
4. ________ he is young, he knows a lot.
   A. Although　B. Because　C. Since　D. As
5. I'll wait here ________ you come back.
   A. since　B. until　C. while　D. as
6. He took a taxi ________ he could arrive on time.
   A. so that　B. so as to　C. in order to　D. such that
7. He walked slowly in order that he ________ not fall.
   A. can　B. might　C. must　D. need
8. No matter how ________, he never gives up.
   A. hard is it　B. hard it is　C. it is hard　D. hard does it
9. You may go out ________ you finish your homework first.
   A. as long as　B. unless　C. so that　D. even if
10. It looks ________ it is going to rain.
    A. even if　B. as if　C. so that　D. in case

### 答案与解析

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | B | `comes` 为瞬间动词，句意为“他一回来我就告诉他”，故用 `The moment`（= `as soon as`），且从句用一般现在时表将来。 |
| 2 | B | 中心词为单数可数名词 `day`，且冠词 `a` 在形容词 `cold` 之前，符合 `such + a/an + adj. + 单数可数名词 + that` 结构。 |
| 3 | B | `hardly … when …` 为固定搭配，意为“刚一……就……”。 |
| 4 | A | 前后分句为“虽然年轻，却懂得很多”的让步关系，且从句为正常陈述语序，故用 `Although`（`As` 表让步时必须将表语 `young` 提前倒装）。 |
| 5 | B | 主句谓语 `wait` 为延续性动词，搭配 `until` 表示“一直等到你回来为止”。 |
| 6 | A | 空格后是含情态动词 `could` 的完整从句，表目的用 `so that`；`so as to` 与 `in order to` 后只能接动词原形。 |
| 7 | B | `in order that` 引导目的状语从句，且主句谓语 `walked` 为一般过去时，从句须用过去式情态动词 `might`。 |
| 8 | B | `no matter how` 后必须紧接被修饰的形容词 `hard`，且从句用陈述语序（主语 `it` + 谓语 `is`），故为 `hard it is`。 |
| 9 | A | 句意为“只要你先做完作业就可以出去”，表示肯定条件用 `as long as`（`unless` 表否定条件“除非”，代入后句意相反）。 |
| 10 | B | 句意为“天看起来好像要下雨了”，`look as if …` 意为“看起来好像……”，且根据客观迹象极可能成真，从句用陈述语气。 |
