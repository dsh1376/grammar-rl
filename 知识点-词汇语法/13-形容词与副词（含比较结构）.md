# 13 形容词与副词（含比较结构）

> **大纲依据**：大纲语法部分要求掌握“形容词和副词（含比较级和最高级）的构成与用法”，词汇部分要求“能正确使用常用形容词、副词并辨析近义、形近词”（详见 `大纲/01-官方考试大纲与解读.md`）。
> **真题分布**：《成人高等教育学士学位英语考试历年真题+标准题库》（2013 版）收录的 10 套真题（下称“《题库》10 套真题”或“原书”）中共 20 题（真题（一）第36、39题，真题（二）第44题，真题（三）第32题，真题（五）第38、45题，真题（六）第34、43、49题，真题（七）第41、44题，真题（八）第31、32、37、44、45、46题，真题（九）第31、32、49题），占 Part III 词汇语法总题量（200 题）的 10%。

本考点在《题库》10 套真题中呈现两种截然不同的考查方式，须分别掌握其判定逻辑：

- **A 类·词义辨析**（14 题）：四个选项同为形容词或副词，依据词义、固定搭配与语境逻辑锁定唯一答案。设题陷阱集中在形近词（`effective` / `affected` / `efficient`）、分词形容词（`interested` / `interesting`）、近义形容词（`bare` / `blank` / `hollow` / `vacant`）及习惯搭配（`a narrow escape`）。
- **B 类·比较结构与语序**（6 题）：考查语法形式与词序规则，包括 `enough` 的修饰位置、`as many as` 与 `as much as` 的可数性区分、倍数表达公式 `twice as much as`、`比较级 + than any other + 单数名词` 排除自身结构，以及 `more than` 引导比较从句。

## 一、考点定位：为什么这样考

形容词与副词在 Part III 中题量稳定，是“词义辨析”与“语法形式”两条考查主线的交汇点：

1. **词义辨析（A 类）占比高（14/20）**：命题人不考查生僻词，而是将**同一语义场或词形相近的词**组合设项（如 `effective` / `affected` / `efficient` 三个形近词加 `sufficient`），或将**同一词根的不同派生词**组合设项（如 `interest` / `interested` / `interesting` / `disinterested`），要求考生通过固定搭配与上下文语义精准定位。
2. **固定搭配是直接得分点**：如 `nothing special`、`a narrow escape`、`be interested in`、`available to sb`、`sincere wishes`。此类题目只要识别出题干中的搭配框架即可直接锁定答案。
3. **比较结构（B 类）考查“结构完整性与语序刚性”**：重点涉及 `enough` 的前置与后置规则、倍数表达公式、比较对象排除自身原则，以及 `than` 引导的比较从句。干扰项通过打乱语序（如 `enough big`、`as enough big`）或杂糅两套公式（如 `twice as more as`）设障，考查语法规则的严密性。
4. **标准解题步骤**：第一步看**空格在句中所作成分**（作定语或表语用形容词，作状语修饰动词、形容词或全句用副词）；第二步看**前后固定搭配信号**（介词、名词或比较连接词）；第三步结合**语境逻辑与核心词义**排除干扰项。

## 二、核心规则

### A 类·词义辨析的核心规则

| 规则 | 判定依据 / 信号 | 例 |
|---|---|---|
| 表语位置用**形容词**（不用副词） | 系动词 `be` / `seem` / `look` / `remain` + 空格 | The medicine is `effective`. |
| 修饰**人**的感受用 `-ed` 分词形容词，修饰**物/事**的特征用 `-ing` 分词形容词 | 看被修饰成分是“产生感受的人”还是“引起感受的事物” | `interested`（人感兴趣的）/ `interesting`（事物有趣的）；We are excited about the exciting news. |
| 过去分词形容词表“被动、已完成状态” | 被修饰名词是动作的承受者 | `abandoned car`（被遗弃的车）；They found an abandoned house by the river. |
| 形近词按**词根 + 后缀的核心语义**区分 | 拆解词根并核对被修饰对象的语义类别 | `effective`（有效果的，重结果）/ `efficient`（效率高的，重投入产出比）；The medicine is effective and the machine is efficient. |
| 习惯搭配优先于字面直译 | 识别题干中的核心名词与固定修饰语 | `a narrow escape`（九死一生）；Our team won a narrow victory in the final. |

### B 类·比较结构与语序的核心规则

| 规则 | 判定依据 / 信号 | 例 |
|---|---|---|
| `enough` 修饰**形容词或副词**时**必须后置** | `形容词/副词 + enough (+ to do)` | `big enough` / `old enough`；This coat is big enough for me. |
| `enough` 修饰**名词**时**前置** | `enough + 名词` | `enough money`；We don't have enough money for the trip. |
| `as many as` 后接**可数名词复数** | 中心名词为可数名词复数 | `as many as 500 people`；As many as two hundred workers joined the strike. |
| `as much as` 后接**不可数名词或度量衡/金额** | 中心名词不可数，或表金钱、时间、重量等整体数量 | `as much as 500 yuan`；He earns as much as ten thousand yuan a month. |
| 倍数表达公式一：`倍数 + as + 原级 + as` | 倍数词、`as + 原级 + as` 三要素缺一不可 | `twice as much as`；This box weighs twice as much as that one. |
| `as ... as` 结构中间**只能填形容词或副词原级** | 严禁在 `as ... as` 中间填入比较级 | `twice as large as`（严禁写 `as larger as`）；Their new house is twice as large as ours. |
| 同类范围比较：`比较级 + than any other + 单数名词` | 主语属于所比较的类别范围之内，必须加 `other` 排除自身 | He runs faster than any other student in his class. |
| `more (...) than` 后可直接引导**省略主语的比较从句** | `than` 兼作从句代词性主语，后直接接谓语动词 | He spends more money than is necessary. |
| 时间副词 `then` 置于句首或句末 | 严禁插入 `形容词/副词 + enough` 等固定结构内部 | She wasn't tall enough to reach the shelf then. |

### B 类补充：倍数、比较省略与形容词/副词位置

本小节补充三类延展规则。其中**倍数结构、`as … as` 与 `so … as` 的区分以及比较从句的省略**在《题库》10 套真题中有直接考查（真题（七）第41题、真题（八）第31题、真题（八）第44题），`the + 比较级 …, the + 比较级 …` 亦见于 Part IV 完形填空（真题（四）第58题）；**多形容词排序与副词位置规则**属于大纲“形容词和副词的构成与用法”规定的掌握内容，《题库》10 套真题的 200 道词汇语法题虽未单独设题，但属于必备语法基础。

| 规则 / 结构 | 判定依据 | 例句 |
|---|---|---|
| `the + 比较级 …, the + 比较级 …` 表“越……越……” | 前后分句均以 `the + 比较级` 开头，其后均保持陈述语序 | The more you read, the more you know. |
| 后半句表泛指评价时省去系动词与主语 | 当后半句为 `the better` / `the worse` 等评价且语义自明时，直接以 `the + 比较级` 收尾 | The sooner you start, the better. |
| 倍数公式一：`倍数 + as + 原级 + as` | 倍数词（`twice` / `three times`）、原级、第二个 `as` 缺一不可 | This box weighs twice as much as that one. |
| 倍数带名词：`倍数 + as many/much + 名词 + as` | 名词为可数复数用 `many`，不可数用 `much` | He has twice as many books as I do. |
| 倍数公式二：`倍数 + 比较级 + than` | 使用比较级时，后面必须搭配连词 `than` | This road is three times longer than that one. |
| `as … as` 的省略：第二个 `as` 后接 `possible` / `ever` 或省略已知主谓 | 第二个 `as` 后为固定缩略词或与主句重复的主谓成分时，省去重复主谓 | Please come as early as possible. |
| `as … as` 的否定式：`not so + 原级 + as` 或 `not as + 原级 + as` | 否定句中第一个 `as` 可替换为 `so`（肯定句中不可用 `so … as`） | He is not so tall as his brother. |
| 否定比较结构后接 `any` 表“任何一个” | `not so/as + 原级 + as + any (other) + 名词` | He is not so tall as any other boy in his class. |
| 多形容词前置定语排序：限定词 → 观点 → 大小 → 形状 → 新旧 → 颜色 → 国籍 → 材料 | 口诀“限观大形新旧颜国材”，越接近名词本质属性的词越紧贴名词 | a lovely little old brown French wooden box / two big grey stone houses |
| 方式副词：置于不及物动词之后；有宾语时置于宾语之后 | 修饰实义动词的动作方式，不可插入及物动词与宾语之间 | He drives his car carefully. |
| 频度副词（`always` / `usually` / `often` / `seldom` / `never`）：位于实义动词之前、系动词 `be` 或第一助动词之后 | 修饰动作发生的频率，位置由谓语动词类型决定 | He always gets up early. / She is never late. |
| `enough` 的位置：修饰形容词或副词时后置；修饰名词时前置 | 依据被修饰词的词性严格区分前后位置 | warm enough / fast enough / enough money |
| 时间、地点副词：置于句末或句首，不可插入固定短语内部 | 避免割裂 `形容词 + enough` 等紧凑结构 | He wasn't old enough then. |

在多形容词并列修饰同一名词的考题中，无论出现几个修饰词，均须严格按照上述左到右顺序排列：主观评价词（观点）永远排在客观属性词之前，而表示本质属性的“国籍、材料”永远紧贴被修饰名词（如 `a small round old brown wooden table`）。

## 三、真题精解

### （一）A 类·词义辨析（14 题）

#### 真题（一）第36题
- **题干**：Taken in time, the medicine can be quite ________.
- **选项**：A. effective　B. affected　C. efficient　D. sufficient
- **答案**：A
- **译文**：只要及时服药，这种药会很有疗效。
- **解题思路**：第一步定位题干信号：主语为 `the medicine`（药物），状语 `Taken in time`（及时服用）给出了药物起效的条件，空格位于系动词 `be` 后作表语，须填表示“有疗效的”形容词。第二步辨析词义与搭配：`effective` 意为“有效的、能产生预期效果的”，专用于描述药物、措施或法律产生预期作用。第三步排除形近干扰项，锁定唯一答案 A。
- **干扰项分析**：
  - B `affected` 是动词 `affect`（影响）派生的过去分词形容词，意为“受到影响的；做作的”，与主语“药物”搭配不当；
  - C `efficient` 意为“效率高的”，强调以较少的时间或资源消耗完成工作，仅用于修饰人、机器、系统或工作方法（如 `an efficient secretary`），不可用于修饰药物疗效；
  - D `sufficient` 意为“数量充足的”，仅描述数量是否够用，与“及时服药产生疗效”的逻辑无关。
- **举一反三**：`effective` 侧重“产生预期结果”（如 `effective medicine`、`effective measures`），`efficient` 侧重“投入产出比高”（如 `efficient workers`、`efficient machines`）。同时须区分动词 `affect`（影响）派生出的 `affected`（受影响的）与名词 `effect`（效果）派生出的 `effective`（有效的）。

#### 真题（一）第39题
- **题干**：There is nothing ________ about a native English-speaking teacher except that he speaks English easily and well.
- **选项**：A. specific　B. especial　C. particular　D. special
- **答案**：D
- **译文**：本土出生的英语外教除了能轻松自如地说一口好英语以外，并没有什么特殊之处。
- **解题思路**：第一步定位题干信号：空格位于复合不定代词 `nothing` 之后作后置定语，构成 `nothing ___ about sb/sth` 框架，且后文 `except that ...`（除了……之外）说明“并无其他特殊之处”。第二步套用核心搭配：`nothing special` 为固定表达，意为“没什么特别的、很寻常”。第三步由此得出唯一答案 D。
- **干扰项分析**：
  - A `specific` 意为“具体的、明确的”，指细节或指示清晰明确，不可与 `nothing` 构成表示“毫无特殊之处”的习惯搭配；
  - B `especial` 虽意为“特别的”，但仅限在正式书面语中作前置定语修饰抽象名词（如 `of especial importance`），不可置于复合不定代词 `nothing` 之后作后置定语；
  - C `particular` 意为“特定的、某一特定的（仅作前置定语）；挑剔的（`be particular about`）”，置于 `nothing` 后须加介词 `in` 构成 `nothing in particular`（没什么特别的事），不可构成 `nothing particular about sb/sth`。
- **举一反三**：复合不定代词（`something` / `anything` / `nothing`）后接形容词作后置定语表“特别的”时，一律使用 `special`（如 `nothing special`、`something special`），不用 `especial` 或 `particular`。

#### 真题（二）第44题
- **题干**：He looked through the pages of advertisements to find jobs ________ to college students during the summer holidays.
- **选项**：A. obtainable　B. available　C. convenient　D. essential
- **答案**：B
- **译文**：他翻阅广告，找寻供大学生做暑假工的工作。
- **解题思路**：第一步定位题干信号：空格修饰名词 `jobs`，且空格后紧接介词短语 `to college students`，表示“可供大学生申请或获得的”。第二步套用核心搭配与语序规则：`available to sb` 为固定搭配，意为“可供某人使用的、某人可获得的”；当形容词带有介词短语补足语作定语时，必须置于被修饰名词 `jobs` 之后。第三步锁定唯一答案 B。
- **干扰项分析**：
  - A `obtainable` 虽意为“可获得的”，但其固定搭配为 `obtainable from/through + 来源/途径`，不可接 `to sb` 表示“面向某群体的”；
  - C `convenient` 意为“方便的”，搭配为 `be convenient for sb`，且描述的是便利程度而非岗位“可申请、可获得”；
  - D `essential` 意为“必不可少的”，`jobs essential to college students` 意为“对大学生必不可少的工作”，与“翻阅广告找暑期工”的语境不符。
- **举一反三**：`available` 作定语修饰名词时，单独使用可前置也可后置（如 `the tickets available today`），带介词短语时必须后置；其核心搭配为 `be available to sb`（供某人使用/获得）与 `be available for sth`（可用于某事）。

#### 真题（三）第32题
- **题干**：The mountain climber had a ________ escape from death.
- **选项**：A. short　B. scarce　C. close　D. narrow
- **答案**：D
- **译文**：这位登山者九死一生了。
- **解题思路**：第一步定位题干信号：空格位于冠词 `a` 与名词 `escape` 之间作定语，后接 `from death`（从死亡中逃脱）。第二步套用固定搭配：英语中表示“侥幸逃脱、九死一生”的固定搭配为 `a narrow escape`，此处 `narrow` 取“勉强的、险些未能成功的”这一引申义。第三步锁定唯一答案 D。
- **干扰项分析**：
  - A `short` 意为“空间短的、时间短暂的”，不具有“惊险、侥幸”之义；
  - B `scarce` 意为“稀缺的、不足的”，仅用于修饰资源、食物或供应品，不可修饰 `escape`；
  - C `close` 虽有“接近的”含义，但表示“千钧一发”时必须构成固定短语 `a close call` 或 `a close shave`，不可与 `escape` 搭配。
- **举一反三**：`narrow` 表示“差距极小的、勉强的”时构成一组高频固定搭配：`a narrow escape`（九死一生）、`a narrow victory`（险胜）、`a narrow majority`（微弱多数）。同考点复现于真题（九）第31题。

#### 真题（五）第38题
- **题干**：In Britain, the best season of the year is probably ________ spring.
- **选项**：A. later　B. latter　C. last　D. late
- **答案**：D
- **译文**：在英国，一年中最好的季节可能是晚春。
- **解题思路**：第一步定位题干信号：空格直接修饰季节名词 `spring`，且句中无任何比较对象或成对指代，需表达一个季节内部的“晚期、末期”。第二步套用词义规则：原级形容词 `late` 置于表示时间段、季节、年代的名词前，表示“……的晚期/末期”，`late spring` 即“晚春”。第三步排除同根变形词，锁定唯一答案 D。
- **干扰项分析**：
  - A `later` 是 `late` 的比较级，意为“更晚的、后来的”，句中不存在两个时间的比较，不可使用比较级；
  - B `latter` 意为“后者的”，只能用于 `the former ... the latter ...` 结构中特指两者中的第二个，不可修饰季节名词；
  - C `last` 意为“上一个的、最后的”，`last spring` 指“去年春天”（特定过去时间），与主句泛指“一年中最好的季节（`the best season of the year`）”在逻辑上冲突。
- **举一反三**：同根四词严格按功能区分：`late`（晚期的，如 `late spring`、`in the late 1990s`）→ `later`（更晚的，比较级）→ `latter`（后者的，与 `former` 配对）→ `last`（最后的、上一个的）。

#### 真题（五）第45题
- **题干**：The lost car of the Johnsons' was found ________ in the woods of the expressway.
- **选项**：A. vanished　B. scattered　C. rejected　D. abandoned
- **答案**：D
- **译文**：约翰逊家丢失的那辆汽车被发现遗弃在高速公路边的树林里。
- **解题思路**：第一步定位题干信号：主语为 `The lost car`（丢失的汽车，单数可数名词），谓语为被动结构 `was found ___`，空格处需填过去分词形容词作主语补足语，说明汽车被发现时所处的状态。第二步辨析词义与动宾关系：汽车是被盗或使用后“抛弃”在树林里的，`abandoned`（被遗弃的、被废弃的）与主语 `car` 构成合理的被动状态关系，`be found abandoned` 即“被发现遭遗弃”。第三步得出唯一答案 D。
- **干扰项分析**：
  - A `vanished` 源自不及物动词 `vanish`（彻底消失、不复存在），既与“在树林里被发现（`was found`）”语义自相矛盾，又不能用于 `be found + 过去分词` 结构作状态补语；
  - B `scattered` 意为“散落的、分散的”，其修饰对象必须是复数名词或集合体，不能描述单数的一辆汽车（`the lost car`）；
  - C `rejected` 意为“被拒绝的、被驳回的”，仅用于修饰提议、申请、计划或次品，不用于描述丢失后被丢弃的车辆。

#### 真题（九）第32题
- **题干**：With the constant change of conditions, the outcome is not always ________.
- **选项**：A. favorable　B. reasonable　C. dependable　D. predictable
- **答案**：D
- **译文**：随着形势的不断变化，结果并非总是可以预见的。
- **解题思路**：第一步定位题干信号：原因状语 `With the constant change of conditions`（随着形势的不断变化）指出前提条件一直在变，主句主语为 `the outcome`（结果），谓语为 `is not always ___`（并非总是……的）。第二步推导因果逻辑：条件不断变化，直接导致结果“难以预先判断”，`predictable` 意为“可预见的、可预测的”，填入后语义严密闭合。第三步锁定唯一答案 D。
- **干扰项分析**：
  - A `favorable` 意为“有利的、赞成的”，“形势变化”并不必然探讨结果是否有利，因果链条不成立；
  - B `reasonable` 意为“合情合理的、公道的”，评价行为、价格或解释是否合乎情理，与条件变化无直接因果关系；
  - C `dependable` 意为“可靠的、值得信赖的”，用于修饰人、朋友、机器或消息来源的可靠性，不用于描述事件结果（`outcome`）能否被预知。
- **举一反三**：由动词 `predict`（预测）派生出形容词 `predictable`（可预测的）与反义词 `unpredictable`（不可预测的）。同时注意区分同词根形容词：`dependable`（可靠的，修饰人或工具）与 `dependent`（依赖的，搭配为 `be dependent on`）。

### （二）B 类·比较结构与语序（6 题）

#### 真题（六）第34题
- **题干**：His little car isn't _______ for five people.
- **选项**：A. enough big　B. big enough　C. as enough big　D. so big enough
- **答案**：B
- **译文**：他的小汽车不够大，容纳不了5个人。
- **解题思路**：第一步定位题干信号：系动词 `isn't` 后接表语，选项均由形容词 `big` 与程度副词 `enough` 组合而成。第二步套用核心语序规则：`enough` 修饰形容词或副词时**必须后置**，即构成 `形容词/副词 + enough` 结构。第三步直接锁定唯一正确语序 `big enough`，选 B。
- **干扰项分析**：
  - A `enough big` 违反 `enough` 修饰形容词必须后置的语法规则；
  - C `as enough big` 既违反 `enough` 后置规则，又缺失同级比较 `as ... as` 的第二个 `as`；
  - D `so big enough` 将程度副词 `so` 与 `enough` 赘余叠用（`so` 只能用于 `so big that ...` 或否定比较 `not so big as ...`）。
- **举一反三**：牢记 `enough` 位置口诀——**名在前、形副后**：修饰名词时前置（`enough money`、`enough time`），修饰形容词或副词时后置（`big enough`、`fast enough`），后常接不定式构成 `形容词/副词 + enough + to do sth`（如 `old enough to vote`）。

#### 真题（七）第41题
- **题干**：Last year he learned ________ he had expected because he worked a lot harder.
- **选项**：A. twice as much as　B. twice as many as　C. twice more　D. twice as more as
- **答案**：A
- **译文**：去年他学到了预期的两倍内容，因为他付出了更多的努力。
- **解题思路**：第一步定位题干信号：空格前为动词 `learned`，空格后为从句 `he had expected`，四个选项均含倍数词 `twice`。第二步套用倍数公式与可数性规则：倍数同级比较公式为 `倍数 + as + 原级 + as`；动词 `learned` 的隐含宾语是“所学的知识或内容”，属于不可数概念，因此原级必须用 `much` 而非 `many`。第三步得出唯一答案 A `twice as much as`。
- **干扰项分析**：
  - B `twice as many as` 中的 `many` 只能指代或修饰可数名词复数，题干中无复数名词，不可选用；
  - C `twice more` 属于 `倍数 + 比较级 + than` 公式的残缺形式，因缺少比较连词 `than` 无法引导从句 `he had expected`；
  - D `twice as more as` 违反“`as ... as` 中间只能填原级”的硬性规则，严禁填入比较级 `more`。
- **举一反三**：倍数表达只有两套合法结构——① `倍数 + as + 原级 + as`（如 `twice as much as`、`three times as large as`）；② `倍数 + 比较级 + than`（如 `twice more than`、`three times larger than`）。凡出现 `as + 比较级 + as` 或 `比较级` 后漏 `than` 的选项，一律直接排除。

#### 真题（八）第31题
- **题干**：________ five hundred people are believed to have drowned.
- **选项**：A. As many as　B. As much as　C. So many as　D. So much as
- **答案**：A
- **译文**：据说多达500人溺水死亡。
- **解题思路**：第一步定位题干信号：本句为肯定陈述句，空格位于数词与复数可数名词 `five hundred people` 之前，表示“多达……”。第二步套用核心规则：肯定句中表示“多达”必须用 `as many/much as`（不可用 `so ... as`）；中心名词 `people` 为可数名词复数，必须用 `many`。第三步锁定唯一答案 A `As many as`。
- **干扰项分析**：
  - B `As much as` 用于修饰不可数名词或金钱、时间、重量等度量衡整体概念，不可修饰可数复数名词 `people`；
  - C `So many as` 与 D `So much as`：`so ... as` 结构仅限于否定句（`not so many/much as`），肯定句中严禁使用。
- **举一反三**：表示数量“多达”时遵循两步判定：① 肯定句一律用 `as ... as`；② 看核心名词可数性——可数复数（如 `people`、`books`、`students`）用 `as many as`，不可数或度量衡总量（如 `rain`、`500 yuan`、`two hours`）用 `as much as`。

#### 真题（八）第44题
- **题干**：It is generally agreed that the Internet has brought people together ________.
- **选项**：A. more than any invention　B. than any other invention　C. than any other invention has　D. more than has any other invention
- **答案**：C
- **译文**：人们普遍认为，比起任何一种其他发明，因特网让人们更亲近了。
- **解题思路**：第一步定位题干信号：主语 `the Internet`（因特网）与选项中的 `invention`（发明）属于种属包含关系（因特网本身就是一项发明），且前文谓语为现在完成时 `has brought`。第二步套用同类比较规则：① 主语属于所比较的类别范围之内时，必须用 `any other + 单数名词`（`any other invention`）排除主语自身；② 从句补出助动词 `has` 代指前文 `has brought people together`，且陈述语序中助动词 `has` 必须置于从句主语 `any other invention` 之后。第三步对照原书答案锁定 C（关于选项 C 缺少比较级 `more` 的题干瑕疵，详见下方存疑说明）。
- **干扰项分析**：
  - A `more than any invention` 缺少 `other`，将因特网自身也包含在被比较的 `any invention` 之中，造成“因特网比包括它自己在内的任何发明都……”的逻辑悖谬；
  - B `than any other invention` 既缺少与前文呼应的比较级 `more`，又未补出助动词 `has`；
  - D `more than has any other invention` 虽包含 `more` 与 `any other invention`，但将助动词 `has` 倒装至主语之前（规范表达应将 `has` 置于主语之后，即 `more than any other invention has`），原书据此将其判为语序错误项。
- **举一反三**：同一范围内的个体与该范围其他个体比较时，固定公式为 `比较级 + than any other + 单数名词`（如 `Shanghai is larger than any other city in China.`）。
> **存疑**：**原书参考答案**：C（核对原书答案时以此为准）；**考场作答建议**：选 C（原书解析明确以“用 `any other invention` 排除自身”且“助动词 `has` 置于主语之后”锁定 C；但题干 `has brought people together` 中并无比较级 `more`，直接接 C 项 `than ...` 会导致句中缺少比较级，实为原题题干漏印了 `more` 或将 C 项开头的 `more` 漏印，完整规范句式应为 `... has brought people together more than any other invention has.`）。

#### 真题（八）第45题
- **题干**：We often advise him not to drink more ________ is good for his health.
- **选项**：A. as　B. that　C. than　D. but
- **答案**：C
- **译文**：我们经常劝他喝酒不要超过有益健康的量（即不要过量饮酒）。
- **解题思路**：第一步定位题干信号：空格前出现比较级 `more`，空格后为无主语的谓语结构 `is good for his health`。第二步套用比较从句规则：比较级 `more` 后必须搭配比较连词 `than`；在 `more (...) than + 谓语` 结构中，`than` 兼作关系代词充当比较从句的主语，表示“超过……的量”。第三步锁定唯一答案 C。
- **干扰项分析**：
  - A `as` 用于原级比较 `as ... as`，不可与比较级 `more` 搭配；
  - B `that` 不可引导比较状语从句，不能与 `more` 构成比较结构；
  - D `but` 表并列转折，无法接在 `more` 后引导比较从句。
- **举一反三**：`more (...) than + 谓语动词` 是固定比较从句结构，其中 `than` 兼作从句主语，不可再添加代词 `it` 或 `what`（如 `drink more than is good for his health`、`spend more money than is necessary`、`take more than is needed`）。

#### 真题（八）第46题
- **题干**：—Did Charles vote in the last election？  —No, he wasn't ________.
- **选项**：A. enough old then　B. then enough old　C. old then enough　D. old enough then
- **答案**：D
- **译文**：——查尔斯在上次选举中投票了吗？  ——没有，他当时年龄不够大。
- **解题思路**：第一步定位题干信号：四个选项均由形容词 `old`、程度副词 `enough` 与时间副词 `then`（当时）三个词排列而成。第二步套用两条语序规则：① `enough` 修饰形容词 `old` 时必须后置，构成不可分割的 `old enough`；② 时间副词 `then` 置于句末作时间状语，不可插入固定结构中间。第三步得出唯一正确语序 `old enough then`，选 D。
- **干扰项分析**：
  - A `enough old then` 将 `enough` 置于形容词 `old` 之前，违反后置规则；
  - B `then enough old` 既将 `then` 误置，又违反 `enough` 后置规则；
  - C `old then enough` 将时间副词 `then` 强行插入 `old enough` 中间，割裂了修饰结构。
- **举一反三**：时间副词 `then`、`today`、`yesterday` 作时间状语时，一律置于句末或句首，严禁插入 `形容词/副词 + enough` 结构内部。

## 四、易错点与陷阱清单

| 陷阱类型 | 具体表现 | 破解方法 |
|---|---|---|
| 形近词混淆 | `effective` / `affected` / `efficient` / `sufficient` | 按词根与适用对象区分：`effective`（有效果的，修饰药/措施）、`affected`（受影响的）、`efficient`（效率高的，修饰人/机器）、`sufficient`（充足的，修饰数量） |
| 分词形容词误用 | `interested` / `interesting` / `disinterested` | 人作主语表感受用 `-ed`，物作主语或被修饰表特征用 `-ing`；`disinterested` = 公正无私的，`uninterested` = 不感兴趣的 |
| 近义“空”词混用 | `blank` / `hollow` / `vacant` / `bare` | 纸面空白用 `blank`、内部中空用 `hollow`、职位/房间空缺用 `vacant`、地表/身体无遮盖用 `bare` |
| 固定搭配望文生义 | 将 `narrow` 仅按字面理解为“空间狭窄”，漏掉“勉强的、差距极小的”搭配义 | 熟记固定搭配 `a narrow escape`（九死一生）、`a narrow victory`（险胜） |
| `enough` 语序颠倒 | 误写 `enough big`、`enough old` | 牢记“名在前、形副后”：`enough + 名词`，`形容词/副词 + enough` |
| 可数性误判 | `as many as` 与 `as much as` 混用 | 核心名词为可数复数（如 `people`）用 `many`；不可数名词或金钱、时间、知识总量用 `much` |
| 倍数公式残缺或杂糅 | 误写 `twice more`（缺 `than`）、`twice as more as`（误用比较级） | 只认两套合法公式：`倍数 + as + 原级 + as` 或 `倍数 + 比较级 + than` |
| 同类比较未排除自身 | 误写 `more than any invention`（包含自身） | 主语属于被比较类别时，必须用 `比较级 + than any other + 单数名词` 排除自身 |
| 比较连词缺失或误换 | 比较级 `more` 后误接 `as` 或 `that` | 凡见比较级 `more` 表比较，连接词一律用 `than`（`more than + 从句`） |
| 程度副词与结论反向 | 题干给出 `slightly injured`，却选 `fatal` / `deadly` | 严格保持题干程度副词（`slightly` 轻微）与推论表语（`not serious` 不严重）语义一致 |
| 时间副词割裂固定结构 | 误写 `old then enough` | 时间副词 `then` 置于句末或句首，严禁插入 `形容词 + enough` 中间 |

## 五、自测（举一反三）

    A. More　B. The more　C. The most　D. Much

    A. twice as many　B. twice as much　C. as twice many　D. twice many as

    A. so careful as　B. as careful than　C. so more careful as　D. careful so as

### 自测答案与解析

1. **B**。主语为 `The new vaccine`（新疫苗），描述疫苗在预防疾病方面“有效果”须用 `effective`；`efficient` 强调人或机器效率高，`sufficient` 指数量充足，`affected` 意为“受影响的”。
2. **B**。主语 `My younger brother` 指人，且后接介词 `in`，构成固定搭配 `be interested in`（对……感兴趣）；`interesting` 用于修饰事物。
3. **A**。复合不定代词 `nothing` 后接形容词作后置定语，固定搭配为 `nothing special`（没什么特别的），与后句 `quite ordinary`（十分普通）呼应。
4. **A**。主语 `The old factory`（旧工厂）处于“被废弃”状态，用 `abandoned`；`vanished` 意为“消失”，与持续状态 `for years` 矛盾；`scattered`（散落的）与 `rejected`（被拒绝的）均不与工厂搭配。
5. **A**。程度副词 `enough` 修饰形容词 `old` 时后置，构成 `形容词 + enough + to do` 结构（`old enough to look after himself`）。
6. **B**。肯定句中修饰可数名词复数 `fifty students` 表“多达”，必须用 `as many as`；`as much as` 用于不可数名词，`so ... as` 仅用于否定句。
7. **A**。倍数同级比较公式为 `倍数 + as + 原级 + as`，中间只能用原级 `large`，故唯一正确结构为 `twice as large as`。
8. **B**。上海属于中国城市范围之内，同类比较必须用 `比较级 + than any other + 单数名词`（`any other city`）排除自身。
9. **C**。比较级 `more` 后必须接比较连词 `than`，引导省略主语的比较从句 `is necessary`。
10. **A**。`a narrow escape` 为固定搭配，意为“侥幸逃脱、九死一生”；`close` 表此义时须搭配 `call` 或 `shave`。
11. **B**。`the + 比较级 …, the + 比较级 …` 表示“越……越……”，句首从句与后半主句均须以 `the + 比较级` 开头，故选 `The more`。
12. **A**。带名词的倍数公式为 `倍数 + as many/much + 名词 + as`，`books` 为可数名词复数，故用 `twice as many`。
13. **A**。同级比较的否定式为 `not so/as + 原级 + as`，故选 `so careful as`；B 项误用 `than`，C 项误加比较级 `more`，D 项语序错误。
14. **C**。多形容词前置定语遵循“大小 → 形状 → 颜色 → 材料”的顺序：`small`（大小）→ `round`（形状）→ `brown`（颜色）→ `wooden`（材料）。
15. **A**。频度副词 `always` 必须位于系动词 `be`（`is`）之后、表语形容词 `late` 之前，故选 `is always`。
