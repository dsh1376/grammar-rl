# 22 省略、替代、平行与否定

> **大纲依据**：官方《考试大纲》“（四）语法”第 8 条“基本句型的结构及其用法”（省略句、否定句、平行并列句均属基本句型的句法演进范畴），并联动第 4 条“常用连接词、冠词的词义及其用法”（`than`、`whether`、`not only ... but also`、`rather than`、`so` / `neither` / `nor` 等连接词的句法搭配）以及第 3 条（比较结构）、第 7 条（复合句从句）、第 10 条（倒装句）。大纲原文见 `大纲/01-官方考试大纲与解读.md`。
> **真题分布**：本考点在《成人高等教育学士学位英语考试历年真题+标准题库》（2013 版）收录的 10 套真题（以下简称“《题库》10 套真题”或“原书”）共 200 道 Part III 词汇语法题中与比较结构、从句、非谓语及倒装深度融合。直接考查本专题核心规则的真题包括：真题（八）第45题（`than` 比较从句省略主语）、真题（四）第49题（`whether ... or not` 让步状语从句省略）、真题（九）第33题（`would rather do ... than do ...` 平行对称）、真题（二）第41题（`rather than do ...` 平行对称）、真题（一）第38题（`not only ...` 并列平行分句）、真题（九）第34题（`no ... other than` 双重否定表肯定）、真题（八）第47题（否定短语前置触发部分倒装，详见 `09-倒装与强调句.md`），以及 Part IV 完形填空真题（五）第57题（代动词 `do` 替代前文谓语）。

## 一、考点定位：为什么这样考

省略、替代、平行与否定这四类语法现象本质上遵循同一条英语句法原则：**在保证表意精确无歧义的前提下，消除冗余重复、保持并列成分结构对称、明确否定辖域**。命题人将这四类规则融入 Part III 单选题中，是因为无需生僻词汇即可精准检验考生对英语句法结构的掌控力——四个选项往往字面汉译相近，唯有依据形式规则才能一步锁定正确答案。

《题库》10 套真题呈现出四条清晰的命题路径：

1. **省略（Ellipsis）：删去与前文完全重合的成分，仅保留语法骨干**。包括：比较状语从句中 `than` 后直接接系动词或谓语动词，省略从句主语（真题（八）第45题 `more than is good for his health`）；让步状语从句中 `whether ... or not` 省略与前文完全重复的动词短语（真题（四）第49题）；将虚拟条件状语从句紧缩为 `without + 名词 + 不定式` 介词短语（真题（八）第43题 `Without the sun's light to warm the earth's surface`）。
2. **替代（Substitution）：用代动词或替代代词顶替前文已出现的实义成分**。包括：用代动词 `do / does / did` 替代前文实义动词短语（完形真题（五）第57题用 `do` 替代 `restrict tree roots`）；用 `do so` 替代前文“动作动词 + 宾语/状语”整体；用 `one / ones / that / those` 替代前文名词；以及用 `so / neither / nor + 助动词/系动词 + 主语` 替代前文肯定或否定谓语（真题（三）第36题 `so are our bodies`，详见 `09-倒装与强调句.md`）。
3. **平行（Parallelism）：并列连词或比较连词连接的两个成分必须在词性与语法形式上完全对称**。包括：`would rather do A than do B` 中 `than` 前后必须同为动词原形（真题（九）第33题）；`Rather than do A, sb. would prefer to do B` 中 `rather than` 后用动词原形与 `to do` 中的原形对称（真题（二）第41题）；`not only ...` 并列分句内部结构平行呼应（真题（一）第38题）。
4. **否定（Negation）：判定否定的作用范围、双重否定的肯定折算以及句首否定的倒装触发**。包括：句首否定短语触发主句部分倒装且谓语不再重复加 `not`（真题（八）第47题 `By no means should we ...`）；`no ... other than` 构成“否定 + 排除 = 唯一肯定”（真题（九）第34题 `In no country other than Britain...` = 只有在英国……）。

**大纲兜底说明**：以下细则属于大纲第 4、8 条规定的必备语法点，虽在《题库》10 套真题的 200 道 Part III 试题中**未单独设空**，但在完形填空、阅读长难句解析、英译汉及写作中高频出现，本文一并系统梳理：不定式省略后保留符号 `to`（如 `He refused to.`）、`one / ones` 与 `that / those` 的替代分工、`all / both / every + not` 构成的部分否定、`not uncommon` 等词缀型双重否定，以及 `I don't think ...` 的否定转移规则。

## 二、核心规则

### 2.1 并列句中的成分省略

由并列连词（`and` / `but` / `or` / `so` / `yet`）连接的两个分句，当后一分句的某一成分与前一分句对应成分在**词形、人称、数和时态上完全一致且省略后不产生歧义**时，可将该重复成分省去。

| 省略成分 | 判定依据与适用条件 | 例句 |
| --- | --- | --- |
| 后分句主语 | 前后两个并列分句共享同一个主语 | `He got up early and (he) caught the first bus.` |
| 后分句主语及助动词 | 两个并列谓语共用同一主语与同一助动词/系动词 | `She sang and (she) danced all night.` |
| 后分句实义动词及宾语/表语 | 后分句仅保留助动词/情态动词/系动词以体现肯定或否定对立 | `I like coffee, but she doesn't (like coffee).` |
| 保留助动词/情态动词、省略实义动词原形 | 前后分句主语不同但动作相同时，保留助动词或情态动词，省去实义动词 | `He can swim, and I can (swim) too.` |
| 并列介词短语中的第二个介词 | 两个宾语受同一个介词支配且由 `and / or` 紧邻连接时，第二个介词可省 | `They arrived in Beijing and (in) Shanghai.` |

**刚性约束**：省略的前提是**前后成分语法功能完全相同且不引发歧义**——若前后分句主语不同，后分句主语绝不可省（如 `He came in and she went out.`）；若前后分句主语单复数不同导致助动词形式不同（如 `was` 与 `were`），后分句助动词绝不可省。

### 2.2 动词不定式中的省略（省略 `to` vs 保留 `to`）

动词不定式的省略分为两类截然不同的语法机制：一类是在并列或使役/感官结构中**省去不定式符号 `to`（保留动词原形）**；另一类是在承前省略结构中**省去后面的动词原形短语（必须保留不定式符号 `to`）**。

| 规则类别 | 判定依据与适用条件 | 例句 |
| --- | --- | --- |
| 并列不定式省去第二个 `to` | 当 `and` / `or` / `than` / `rather than` 连接两个表示连续或选一关系的不定式时，第二个 `to` 省略（但若表正反对比，如 `to be or not to be`，则第二个 `to` 必须保留） | `I want to sit down and rest.` |
| 承前省略动词短语时**必须保留 `to`** | 在 `want / wish / hope / expect / like / love / plan / try / mean / refuse / promise / ought / used / be able / be going` 后，为避免重复前文已出现的动词短语，省去动词原形但**必须保留符号 `to`**（若原不定式为 `to be ...` 或 `to have done`，则须保留 `to be` 或 `to have`） | `I asked him to help me, but he refused to.` |
| 主动语态感官动词与使役动词后省 `to` | 在主动语态 `see / hear / watch / notice / feel` 及 `make / let / have` 后作宾补时，必须用不带 `to` 的不定式（变被动时 `to` 必须还原，详见 `21` 号文档 2.5 节） | `I saw him enter the room.` |
| 区分不定式符号 `to` 与介词 `to` | 在 `look forward to / object to / be used to（习惯于）/ devote oneself to / stick to / contribute to` 中，`to` 是介词，后接名词或动名词 `doing`，不可按不定式规则省略 | `I'm looking forward to seeing you.` |
| 情态动词与 `had better / would rather` 后省 `to` | 情态动词（`can / may / must / should / need`）及 `had better`、`would rather`、`cannot but`（不得不）后一律直接接动词原形 | `You must finish it today.` |

### 2.3 比较状语从句中的省略

比较连词 `than` 与 `as` 引导的是**比较状语从句**。从句中凡与主句重复的主语、谓语或表语均可按规则省略，从而形成紧凑的考场高频结构。

| 省略结构 | 判定依据与适用条件 | 例句 |
| --- | --- | --- |
| `more / less + (n.) + than + 单数谓语（is / was / should be）` | 当比较从句表示“超出/低于应有或有益的量”时，从句主语（如 `what / the amount that`）固定省略，`than` 在形式上直接充当从句主语并接单数谓语 `is / was` | `He drinks more than is good for him.` |
| `than / as + 主语 + 代动词（do / does / did / 助动词 / be）` | 当从句主语与主句主语不同、但谓语动词相同时，保留从句主语并用相应助动词/代动词替代实义动词，省略后面的重复成分 | `She studies harder than I do.` |
| `as + adj./adv. + as + 名词/代词 (+ be/助动词)` | 同级比较从句中，与主句相同的表语形容词必须省略，句末的系动词 `be` 或助动词可保留也可省略 | `He is as tall as his father (is).` |
| 比较从句中保留特指替代词 `that / those` | 当比较的是两个不同主体的同类属性（如两地天气、两国人口）时，从句主语不可直接省略，必须用 `that`（代单数/不可数）或 `those`（代复数）替代 | `The weather in Beijing is colder than that in Guangzhou.` |
| `than / as` 后保留完整主谓结构 | 当从句的主语和谓语与主句有所不同或涉及时态对比时，保留“主语 + 助动词/代动词”以明确比较基准 | `He works harder than she does.` |

**考场重点提示**：在真题（八）第45题 `not to drink more than is good for his health` 中，切勿因 `than` 后直接紧跟系动词 `is` 而误选关系代词 `that` 或 `which`——只要空格前有比较级 `more / less / fewer / worse`，连接词**100% 锁定 `than`**，其后的 `is` 正是省略了从句主语后的比较从句谓语（详见 `13-形容词与副词（含比较结构）.md`）。

### 2.4 时间、条件、让步状语从句中的省略（分词紧缩句）

在 `when / while / as / once / until`（时间）、`if / unless`（条件）、`though / although / even if / whether ... or`（让步）、`as if / as though`（方式）引导的状语从句中，只有同时满足以下两个条件，才可将从句中的“**主语 + 系动词/助动词 `be`**”一并省略，形成“**连词 + 现在分词 / 过去分词 / 形容词 / 介词短语 / 名词**”的紧缩结构：
1. **条件一**：从句谓语中含有系动词或助动词 `be`；
2. **条件二**：**从句主语与主句主语完全一致**（唯一例外是固定虚指结构 `if possible / if necessary / if any / if so / when necessary`，其省略的是虚主语 `it is/was`）。

| 紧缩结构类型 | 判定依据与还原形式 | 例句 |
| --- | --- | --- |
| `when / while + 现在分词 / 过去分词` | 从句主语 = 主句主语；主句主语与分词为主动关系用 `doing`，为被动关系用 `done`（还原为 `When he is compared...`） | `When compared with his brother, he works harder.` |
| `if / unless + 形容词 / 过去分词` | 省略 `it is`（固定紧缩）或省略“与主句相同的主语 + `be`”（如 `Unless [it is] changed...`） | `If possible, please reply before Friday.` |
| `though / although + 形容词 / 分词` | 从句主语 = 主句主语，省略 `he was`（还原为 `Though he was tired...`） | `Though tired, he kept working.` |
| `whether ... or not` 省略重复谓语 | `or not` 后省去与 `whether` 后完全重复的主谓宾结构（还原为 `Whether you like it or do not like it`） | `Whether you like it or not, you must do it.` |
| 用介词短语 `without / but for` 紧缩条件从句 | 将否定条件从句 `If there were no ...` 紧缩为介词短语 `Without + 名词 (+ to do)`，真题（八）第43题即为此结构 | `Without the sun's light to warm the earth, no life could exist.` |
| `if any / if ever / if anything / if so / if not` | 固定省略短语：`if any`（即便有的话，指数量）、`if ever`（即便有过的话，指频度）、`if so`（如果是这样的话） | `Correct the mistakes, if any.` |

**核心排错铁律**：若状语从句主语与主句主语不一致（且不属于 `if possible / if any` 等固定虚主语短语），则**绝对不能省略从句主语**，否则会造成“垂悬分词”语法错误（主语不一致时须保留自身逻辑主语构成独立主格结构，详见 `03-非谓语动词.md`）。

### 2.5 定语从句与名词性从句中的连接词省略边界

| 规则类别 | 判定依据与适用条件 | 例句 |
| --- | --- | --- |
| 限制性定语从句中关系代词作**宾语**或**表语**可省 | 当关系代词 `that / which / whom` 在限制性定语从句中充当动词宾语、介词宾语（介词后置时）或表语时，可省略 | `The book (that) I bought is interesting.` |
| 定语从句中关系代词作**主语**或处于**介词正后方**绝不可省 | ① 从句紧跟谓语动词（缺主语）时，`who / which / that` 严禁省略；② “介词 + `which / whom`”结构中关系代词严禁省略；③ 非限制性定语从句（有逗号）的关系词严禁省略 | `The man who came is my uncle.` |
| 先行词为 `the reason / the way / the time` 时的省略 | `the reason (why / that) ...`、`the moment / time (when / that) ...` 中的关系词可省；先行词为 `the way` 且在从句中作方式状语时，只能用 `that`、`in which` 或**直接省略**（严禁写 `*the way how`） | `The reason (why) he left is unknown.` |
| 及物动词后的**单个**宾语从句可省略 `that` | `think / believe / say / know / hope / find` 等动词后接单个陈述宾语从句时，连接词 `that` 可省；但若后接**两个并列的 `that` 宾语从句**，**第二个 `that` 绝对不能省略** | `I think (that) he is right.` |
| 主语从句（句首）、表语从句、同位语从句的 `that` 绝不可省 | ① 位于句首的主语从句 `That ...` 绝不可省 `that`；② 同位语从句（如 `the fact / news / idea that ...`）中的 `that` 绝不可省 | `The fact that he lied surprised us.` |
| 介词后（除 `except / in / but` 外）绝不用 `that` 引导宾语从句 | 介词后的名词性从句若表“是否”必须用 `whether`（不用 `if`），若缺成分则用 `what / who / which`，且连接词一律不可省略 | `It depends on whether he agrees.` |

### 2.6 替代之一：代动词 `do / does / did`、`do so` 与 `so / neither / nor` 倒装替代

为避免重复前文已经出现过的实义动词或整个谓语短语，英语使用专门的代动词结构进行替代：

| 替代结构 | 适用范围与句法规则 | 例句 |
| --- | --- | --- |
| `do / does / did` | 替代前文已出现的**实义动词（或实义动词 + 宾语）**，其时态与单复数必须严格依照**当前分句的主语与时间状语**确定 | `He works harder than I do.` |
| `do so`（`does so / did so / doing so / done so`） | 强调整体替代前文已出现的**“动态实义动词 + 宾语/状语”整块谓语事件**（不能替代 `know / like / see` 等静态感知动词） | `He asked me to leave, and I did so.` |
| `so + 助动词/系动词/情态动词 + 新主语` | 表示前一句的**肯定情况**也同样适用于另一个主语（采用部分倒装，助动词类型与前句谓语严格对应，详见 `09`） | `He likes tea, and so do I.` |
| `neither / nor + 助动词/系动词/情态动词 + 新主语` | 表示前一句的**否定情况**也同样适用于另一个主语（采用部分倒装，助动词不再加 `not`） | `He can't swim, and neither can I.` |
| `so + 同一主语 + 助动词/系动词/情态动词`（不倒装） | 主语与前句指向同一人/物，采用陈述语序，表示“**某人/某物的确如此**”（对前句事实予以确认赞同） | `— He works hard. — So he does.` |
| `So it is with ...` / `It is the same with ...` | 当上一句既包含实义动词又包含系动词，或既有肯定又有否定，无法用单一助动词倒装替代时，固定用此句型表“……也是如此” | `Tom is clever and works hard. So it is with Mary.` |

**代动词匹配的四条铁律**：
1. 前句谓语是**系动词 `be`** → 后句替代必须用 `be` 的对应形式（如真题（三）第36题 `so are our bodies`），严禁用 `do`。
2. 前句谓语含**情态动词（`can / will / must / should`）或完成时助动词 `have / has / had`** → 后句替代必须重复该情态动词或 `have / has / had`，严禁用 `do`。
3. 前句谓语是**一般现在时或一般过去时的实义动词** → 后句替代必须用 **`do / does / did`**（如完形真题（五）第57题 `they do not restrict tree roots the way concrete squares do`，用 `do` 替代 `restrict tree roots`）。
4. 代动词的**时态与人称数**完全由**新分句自身的主语与时间状语**决定（如 `He studies harder now than he did last year.`，前句用现在时 `studies`，后句有 `last year` 故代动词必须用过去时 `did`）。

### 2.7 替代之二：名词性替代词 `one / ones`、`that / those` 与 `it` 的精确分工

| 替代词 | 被替代名词的性质 | 限定条件与语义特征 | 例句 |
| --- | --- | --- | --- |
| `one` / `ones` | **可数名词**（`one` 代单数，`ones` 代复数） | 表**泛指**“同类事物中的任意一个/一些”；前面若有形容词修饰须写为 `a/an + adj. + one` 或 `adj. + ones`，**绝不能替代不可数名词** | `I need a pen. Do you have one?` |
| `the one` / `the ones` | **可数名词**（单数/复数） | 表**特指**“同类中的那一个/那些”，后常接定语从句或介词短语修饰（其中 `the ones` 在后接 `of` 短语时多用 `those`） | `This is the one I want.` |
| `that` | **不可数名词**或**单数可数名词** | 表**后置特指替代**（等于 `the + 前文不可数/单数名词`），专用于比较或并列结构中，其后**必须紧跟 `of / in` 等介词短语或分词短语**作后置限定 | `The weather here is better than that of Beijing.` |
| `those` | **可数名词复数** | 表**后置特指替代**（等于 `the + 前文复数名词`），其后必须紧跟介词短语、分词短语或定语从句作后置限定 | `The books on this shelf are newer than those on that one.` |
| `it` | **单数可数名词**或**不可数名词** | 指代前文提到的**同一个具体事物本身**（同一实体，非同类中的另一个），其后不能带 `of` 等后置定语 | `I lost my pen; I must buy one.`（对比：`I found my pen; it was in my bag.`） |

### 2.8 平行结构：并列与比较连词两侧的形态对称铁律

凡由并列连词（`and`、`or`、`but`）、关联并列连词（`not only A but (also) B`、`either A or B`、`neither A nor B`、`both A and B`、`not A but B`、`A as well as B`）或比较选择连词（`would rather A than B`、`prefer A to B`、`prefer to do A rather than do B`）连接的两个成分 A 与 B，必须在**词性、非谓语形式或从句类型上保持 100% 对称**（即：名词对名词、形容词对形容词、动名词 `doing` 对动名词 `doing`、带 `to` 不定式对带 `to` 不定式、动词原形对动词原形、从句对从句）。

| 核心平行句型 | 两侧对称要求（A 与 B 的强制词形） | 例句 |
| --- | --- | --- |
| `not only A but (also) B` | A 与 B 词性、语法形式完全相同（若 `Not only` 置于句首，则前分句部分倒装，后分句不倒装，见 `09`） | `She not only sings well but also dances beautifully.` |
| `prefer A to B` | 此处 `to` 为**介词**，A 与 B 必须同为**名词**或同为**动名词 `doing`**（严禁写 `*prefer doing to do`） | `I prefer reading to watching TV.` |
| `prefer to do A rather than do B` | `prefer` 后接不定式 `to do A`，`rather than` 后接**动词原形 `do B`**（`rather than` 可提至句首：`Rather than do B, sb. would prefer to do A`） | `I prefer to walk rather than take a bus.` |
| `would rather do A than do B` | `would rather` 后与 `than` 后必须同为**动词原形** | `I'd rather walk than take a bus.` |
| `either A or B` / `neither A nor B` | A 与 B 形式完全对称；连接两个主语时，谓语动词遵循**就近原则** | `Either you or he is right.` |
| `both A and B` | A 与 B 形式完全对称；连接两个主语时，谓语动词**一律用复数** | `She is both clever and diligent.` |
| `not A but B` / `A rather than B` | A 与 B 形式完全对称；连接两个主语时，`not A but B` 按 B 就近一致，`A rather than B` 按 A 一致 | `He is not a teacher but a doctor.` |

**考场三步对称检验法**：
1. **找准连词枢纽**：先在题干中圈出 `and / or / but / than / rather than / to / not only ... but also` 等对称枢纽词。
2. **锁定已知侧形式**：观察空格对面那一侧已知成分的精确语法形态（是动词原形 `do`、过去式 `did`、动名词 `doing` 还是带 `to` 不定式 `to do`）。
3. **镜像复制选答案**：直接将空格处选成与已知侧完全相同的形态（如真题（九）第33题 `___ do it myself than try...` 中，`than` 右侧是原形 `try`，左侧是原形 `do`，故空格锁定后接原形且能与 `than` 搭配的 `I'd rather`）。

### 2.9 否定结构（一）：全部否定、部分否定与双重否定

| 否定类别 | 固定触发标志词 | 精确逻辑语义 | 例句 |
| --- | --- | --- | --- |
| 全部否定（零肯定） | `neither`（两者都不）、`none`（三者及以上都不）、`nobody / no one`（没人）、`nothing`（没什么）、`never`（从不）、`nowhere`（无处）、`no + 名词` | 100% 否定，“全都不、一个也没有” | `None of the answers is correct.` |
| 部分否定（不完全否定） | 总括词（`all / both / every / everybody / everything / always / altogether / entirely / completely`）与 `not` 在同一句中共现（无论 `not` 在前还是在后） | **并非全部都……**（有的是，有的不是） | `Not all the students passed the exam.`（`= All the students did not pass the exam.`） |
| 两者部分否定 | `not both ...` 或 `both ... not ...` | 并非两个都……（其中一个是，另一个不是；若表“两个都不”必须用 `neither`） | `Not both of them are correct.` |
| 词缀/词汇型双重否定 | `not / never + 含否定前缀或否定意义的词`（如 `not uncommon`、`not impossible`、`not infrequently`、`not without reason`） | 负负得正，表**强肯定**（`not uncommon` = 非常常见） | `It is not uncommon to make mistakes.` |
| 伴随型双重否定 | `never / not / no ... without ...`、`cannot ... without ...` | 每次……必定……；每逢……无不…… | `He never goes out without an umbrella.` |
| 排除型双重否定 | `no / nothing / nobody ... other than / but / except ...` | **只有……才……；除……之外别无……** | `In no country other than Britain can one experience four seasons in a day.`（真题（九）第34题） |

**核心区分铁律**：当汉语要表达“所有学生都没及格”或“他们俩都没来”时，英语**严禁写成 `All the students didn't pass.` 或 `Both of them didn't come.`**（这两句在英语中永远只能解释为“并非所有学生都及格”“并非他们俩都来了”的部分否定）；要表达全部否定，必须改用全否词 `None of the students passed.` 与 `Neither of them came.`。

### 2.10 否定结构（二）：否定转移（Transferred Negation）

否定转移是指在特定主从复合句中，逻辑上属于宾语从句的否定词 `not` 在语法形式上前移到了主句谓语动词上。**发生否定转移必须同时满足以下三个条件**：
1. **动词条件**：主句谓语动词属于表示“看法、臆断、相信、推测”的心理认知动词——核心词仅限 **`think`、`believe`、`suppose`、`imagine`、`expect`、`reckon`、`guess`、`feel`**（以及表象系动词 `seem / appear` 后接不定式的结构）；
2. **人称条件**：主句主语必须是**第一人称**（`I` 或 `we`）；
3. **时态与修饰条件**：主句谓语为**一般现在时**，且主句谓语前无情态动词或程度副词修饰。

| 句法规则与例外 | 表层语法形式 | 实际语义与反意疑问句规则 | 例句 |
| --- | --- | --- | --- |
| 标准否定转移结构 | `I/We don't + think / believe / suppose / imagine / expect + 肯定形式宾语从句` | 形式否定主句，语义否定从句（从句内部绝不可再加 `not`，否则变成双重否定） | `I don't think he is right.`（我认为他不对） |
| 否定转移句的反意疑问句 | 主句为 `I/We don't think/believe/suppose + 从句` | 附加疑问句的**助动词、人称代词必须与宾语从句对齐**，且因全句已含否定 `don't`，反意疑问部分必须用**肯定形式**（若主句主语是第二、三人称，如 `He doesn't think...`，则反意疑问句仍跟主句用 `does he?`） | `I don't think he is right, is he?` |
| **绝不发生否定转移的例外动词** | `hope`、`wish`、`fear`、`be afraid`、`doubt`、`know`、`realize` | 上述动词**绝对不能否定转移**，“我希望他别来”必须将否定留在从句中，写作 `I hope he won't come.`（严禁写 `*I don't hope...`） | `I hope he won't come.` |
| `seem / appear / expect / happen` + 不定式的否定前移 | `Sb./Sth. doesn't seem / appear to do...` | 否定助动词移至 `seem / appear` 前，等同于 `seem / appear not to do...` | `He doesn't seem to know it.`（他似乎不知道此事） |
| 主句否定 + `because` 从句的辖域区分 | `主语 + didn't do ... because ...` | ① `because` 前无逗号时，否定常转移管辖 `because` 从句（意为“并不是因为……才做某事”）；② 若表“因为……所以没做某事”，应将 `Because` 从句提至句首或在 `because` 前加逗号隔断否定辖域 | `Because I was ill, I didn't come.`（对比：`I didn't come because I was forced to, but because I wanted to help.`） |

### 2.11 否定词置于句首触发的部分倒装（最小核心规则）

当否定副词或含否定意义的介词短语（`never`、`seldom`、`rarely`、`little`、`hardly`、`scarcely`、`barely`、`no sooner`、`not only`、`not until`、`by no means`、`in no case`、`in no way`、`on no account`、`under no circumstances`、`at no time`、`in no country`）置于句首时，主句必须采用**部分倒装**（即将助动词 `do/does/did/have/has/had`、系动词 `be` 或情态动词提到主语之前）：

- `Never have I seen such a wonderful film.`
- `Little did he know that danger was near.`
- `By no means should we look down on those who are less lucky in life than we are.`（真题（八）第47题）

**刚性约束**：句首触发词本身已承担全句否定功能，倒装后的谓语部分**绝对不能再加否定词 `not`**（否则构成双重否定，导致句意完全颠倒）。完整倒装体系详见 `09-倒装与强调句.md`。

## 三、真题精解

### 真题（八）第45题
- **题干**：We often advise him not to drink more ________ is good for his health.
- **选项**：A. as　B. that　C. than　D. but
- **答案**：C
- **译文**：我们经常建议他不要过量饮酒。
- **解题思路**：
  1. **定位题干信号**：空格前有比较级 `more`，空格后直接紧跟单数系表谓语结构 `is good for his health`（缺少主语）。
  2. **套用核心规则**：根据规则 2.3，比较级 `more` 必须与连词 `than` 呼应引导比较状语从句；当比较从句的主语（即前文隐含的不可数抽象量“他饮酒的量”）与主句语义重复时，从句主语省略，`than` 兼作关系代词在从句中充当主语并直接带单数谓语 `is`（完整还原为 `more than the amount that he drinks is good for his health`）。
  3. **得出唯一答案**：唯一能与比较级 `more` 搭配且兼作比较从句主语的词是 `than`，故选 C。
- **干扰项分析**：
  - A. `as` —— `as` 引导同级比较从句时必须与前文的 `as` 或 `so` 呼应构成 `as … as`，不能与比较级 `more` 搭配。
  - B. `that` —— `that` 只能引导定语从句或名词性从句，不能与 `more` 构成“超过……程度”的比较从句。
  - D. `but` —— `but` 表转折，无 `more … but` 的比较搭配。
- **举一反三**：`more / less than + is / was + 形容词` 是固定主语省略结构，谓语动词单复数恒用**单数** `is / was`（因省略的是抽象程度或数量）：`He spends more money than is necessary.` / `She eats more than is good for her.`。比较结构的完整体系详见 `13-形容词与副词（含比较结构）.md`。

### 真题（四）第49题
- **题干**：________ or not, you are going to face him one day.
- **选项**：A. If you like it　B. Whether you like it　C. However you like it　D. Whether do you like it
- **答案**：B
- **译文**：无论你喜不喜欢，总有一天要面对他。
- **解题思路**：
  1. **定位题干信号**：空格位于句首，后接 `or not` 及逗号隔开的主句 `you are going to face him one day`。
  2. **套用核心规则**：根据规则 2.4，表示“无论是否……”的让步状语从句必须由 `whether … or not` 引导（`or not` 后省略了与前文重复的 `(you do) like it`）；且一切状语从句内部必须采用**陈述语序**（`连词 + 主语 + 谓语`）。
  3. **得出唯一答案**：同时满足 `whether … or not` 固定搭配与陈述语序 `you like it` 的只有 `Whether you like it`，故选 B。
- **干扰项分析**：
  - A. `If you like it` —— `if` 引导条件状语从句，不能与 `or not` 搭配引导让步状语从句。
  - C. `However you like it` —— `however` 引导让步状语从句意为“无论以何种方式/无论多么”，不与 `or not` 构成选择让步搭配。
  - D. `Whether do you like it` —— 语序错误，状语从句严禁使用疑问倒装语序 `do you like`。
- **举一反三**：`whether … or not` 既可引导让步状语从句，也可引导名词性从句，从句内部一律保持陈述语序；常见紧缩形式还有 `whether by accident or design`（不管是有意还是无意）、`believe it or not`（信不信由你）。状语从句省略的主语一致原则详见 `08-状语从句与连词.md`。

### 真题（五）第57题（Part IV 完形填空）
- **题干**：…and they do not restrict tree roots the way concrete squares ________.（A. doing　B. done　C. did　D. do）
- **答案**：D
- **译文**：……而且它们不会像混凝土方砖那样限制树根生长。
- **解题思路**：
  1. **定位题干信号**：名词短语 `the way` 充当连词引导方式状语从句，从句主语为复数名词 `concrete squares`，空格处缺少从句的**限定谓语动词**，且其语义重复主句的实义动词短语 `restrict tree roots`。
  2. **套用核心规则**：根据规则 2.6，替代前文实义动词短语须使用代动词 `do`；代动词的时态与数必须由其所在分句的主语与时间决定——全句为客观陈述（主句 `do not restrict` 为一般现在时），从句主语 `concrete squares` 为复数，故代动词须用一般现在时复数形式 `do`。
  3. **得出唯一答案**：填入 `do` 构成完整方式状语从句，故选 D。
- **干扰项分析**：
  - A. `doing`、B. `done` —— 均为非谓语动词形式，不能单独充当方式状语从句的限定谓语。
  - C. `did` —— 时态错误，上下文均为客观说明的一般现在时，无过去时间依据。
- **举一反三**：代动词的唯一考点在于“先按被替代谓语定词类（实义动词用 `do`、系动词/被动用 `be`、完成时用 `have`），再按新主语和新时间变时态与单复数”：`He studies harder than he did last year.`（过去时间用 `did`）；`She runs faster than her brother does.`（第三人称单数用 `does`）。

### 真题（九）第33题
- **题干**：________ do it myself than try to persuade such a silly fellow like him.
- **选项**：A. I'd like　B. I'd rather　C. I'd better　D. I'd like to
- **答案**：B
- **译文**：我宁愿自己做，也不愿去劝说像他那样的傻瓜（来做）。
- **解题思路**：
  1. **定位题干信号**：空格后为动词原形短语 `do it myself`，句中出现比较连词 `than`，且 `than` 后同样为不带 `to` 的动词原形 `try`。
  2. **套用核心规则**：根据规则 2.8，能与后文 `than + 动词原形` 呼应、且自身后接不带 `to` 动词原形的固定平行结构唯有 `would rather do A than do B`（缩写为 `'d rather do A than do B`）。
  3. **得出唯一答案**：填入 `I'd rather` 与后文 `do … than try …` 严密构成 `would rather do A than do B`，故选 B。
- **干扰项分析**：
  - A. `I'd like` —— `would like` 后接动作必须带不定式符号 `to`（`would like to do`），不能直接接动词原形 `do`。
  - C. `I'd better` —— `had better do` 仅表“最好做某事”，不具有比较含义，后续绝不能搭配 `than`。
  - D. `I'd like to` —— `would like to do` 不能直接与 `than do` 搭配（若表达“更喜欢做 A 而不是做 B”，须用 `would like to do A rather than do B` 或 `prefer to do A rather than do B`）。
- **举一反三**：`would rather do A than do B` 与 `prefer to do A rather than do B` 均表“宁愿做 A 而不愿做 B”，两者的共同铁律是：`than / rather than` 之后都用**不带 `to` 的动词原形**；区别在于 `would rather` 后接原形 `do A`，而 `prefer` 后接带 `to` 的不定式 `to do A`。

### 真题（二）第41题
- **题干**：Rather than ________ quietly by the fireside, he'd prefer to take a long walk in the countryside on Sundays however cold it might be.
- **选项**：A. sit　B. to sit　C. sitting　D. sat
- **答案**：A
- **译文**：比起安静地坐在火边，他更喜欢周日的时候在乡村散步，无论天气有多冷。
- **解题思路**：
  1. **定位题干信号**：句首为 `Rather than ________`，主句谓语为 `he'd prefer to take`。
  2. **套用核心规则**：根据规则 2.2 与 2.8，本句是将 `would prefer to do A rather than do B` 中的 `rather than do B` 提至句首强调；在该结构中，`rather than` 之后的动词无论置于句尾还是提至句首，一律省略不定式符号 `to`，使用**动词原形**。
  3. **得出唯一答案**：空格处应填动词原形 `sit`，故选 A。
- **干扰项分析**：
  - B. `to sit` —— 与 `would prefer to do` 搭配时，`rather than` 后严禁保留 `to`。
  - C. `sitting` —— 动名词无法与主句的不定式 `to take` 构成 `prefer to do A rather than do B` 配对。
  - D. `sat` —— 过去式不能接在句首 `Rather than` 之后与 `would prefer to take` 配对。
- **举一反三**：对比 `prefer` 的两套高频句型，切勿混搭：① `prefer A to B` 中 `to` 是介词，A 和 B 必须同为名词或动名词 `doing`（如 `He prefers walking to sitting.`）；② `prefer to do A rather than do B` 中前用 `to do`、后用原形 `do`。

### 真题（一）第38题
- **题干**：If students can't focus on the spoken word of the teacher, they not only lose to ________ learn; they actually lose ability to learn.
- **选项**：A. desire　B. power　C. need　D. wish
- **答案**：A
- **译文**：如果学生不注意听老师说的话，他们不但会丧失求知欲，也会失去学习的能力。
- **解题思路**：
  1. **定位题干信号**：分号连接两个平行分句 `they not only lose … ; they actually lose ability to learn`（注：原书题干前分句 `lose to ________ learn` 系排版语序印误，标准语序应为 `lose (the) ________ to learn`，与后分句 `lose (the) ability to learn` 完全平行对称）。
  2. **套用核心规则**：根据规则 2.8 的平行结构对称性与名词词义辨析，两个分句由递进结构 `not only … ; … actually …` 连接，宾语位置形成“主观意愿（求知欲）”与“客观能力（`ability to learn`）”的递进呼应；四个选项中，`desire to learn` 专指强烈的“求知欲/学习渴望”，与 `ability to learn`（学习能力）构成由“不想学”到“不能学”的严密语义递进。
  3. **得出唯一答案**：填入 `desire` 最契合递进平行语境，故选 A。
- **干扰项分析**：
  - B. `power` —— 指“权力、力量、电力”，表“做某事的能力”时与后分句的 `ability` 语义重复，无法构成 `not only … actually …` 的递进关系。
  - C. `need` —— 指客观上的“需要、必要性”，学生走神并不会丧失客观上的学习需要。
  - D. `wish` —— 多指具体的“愿望、祝愿”（常带双宾语或从句），不如 `desire to learn`（求知欲）地道稳固。
- **举一反三**：利用平行结构的对称性解词汇题是考场重要技巧——当句中出现 `not only … but also …`、分号并列或对比连词时，先找准另一半的已知核心词（如本题的 `ability to learn`），再根据“同义并列”或“递进对照”关系反推空格词义。

### 真题（九）第34题
- **题干**：In no country ________ Britain can one experience four seasons in the course of a single day.
- **选项**：A. more than　B. other than　C. rather than　D. better than
- **答案**：B
- **译文**：除了英国，其他任何国家的人们都不可能在一天之内体验到四季的变化。
- **解题思路**：
  1. **定位题干信号**：句首为否定介词短语 `In no country`，空格后为国家专有名词 `Britain`，主句为部分倒装结构 `can one experience four seasons in the course of a single day`。
  2. **套用核心规则**：根据规则 2.9，句意表达“唯有在英国，人们才能在一天之内体验四季”，句首已有全否定词 `no country`，空格处需填入表示“除了……之外（不包括）”的介词短语 `other than`（`= except`），构成双重否定结构 `no … other than …`（“除了……之外没有哪个……” = “只有……”）。
  3. **得出唯一答案**：填入 `other than` 构成双重否定表唯一肯定，故选 B。
- **干扰项分析**：
  - A. `more than` —— 意为“多于、超过、不仅仅”，不能接在 `no country` 与 `Britain` 之间表排除。
  - C. `rather than` —— 意为“是……而不是……”，用于平行取舍，不具有 `except`（除……之外）的排除范围功能。
  - D. `better than` —— 意为“比……更好”，语法与句意均无法嵌入 `In no country ________ Britain`。
- **举一反三**：掌握三个带 `than` 的高频短语精准分工：① `other than` = `except / not including`（除了……之外，常与 `no / nobody / nothing` 构成双重否定）；② `rather than` = `instead of`（而不是，连接平行成分）；③ `more than` = `over / very`（超过；非常）。

### 真题（八）第47题（简要）
- **题干**：By no means ________ look down on those who are less lucky in life than we are.
- **选项**：A. we should　B. should we　C. we should not　D. should we not
- **答案**：B
- **译文**：我们绝不能看不起那些在生活中没有我们幸运的人。
- **解析**：① **定位题干信号**：句首为含否定意义的介词短语 `By no means`（绝不），空格后为动词原形短语 `look down on`。② **套用核心规则**：根据规则 2.11，否定介词短语置于句首时，主句必须采用**部分倒装**（将情态动词 `should` 提至主语 `we` 之前）；同时，句首 `By no means` 已承担全句否定功能，倒装谓语严禁再加 `not`（否则 D 项 `should we not` 变成双重否定“并非不该看不起”，句意完全颠倒）。③ **得出唯一答案**：故选 B。完整触发词清单与同类真题详见 `09-倒装与强调句.md`。

## 四、易错点与陷阱清单

| 陷阱类型 | 出题套路 | 破解方法 |
| --- | --- | --- |
| **比较从句主语省略误判** | 在 `more/less … than` 后设置 `that/which/as` 等干扰项，诱导考生按定语从句选连接词（如真题（八）第45题 A、B） | 见比较级 `more/less/-er` 先找唯一搭档 `than`；若空格后直接跟单数谓语 `is/was + 形容词`，说明从句主语因重复而省略，`than` 兼作从句主语 |
| **让步从句误用倒装或 `if`** | 把 `Whether you like it or not` 写成疑问倒装 `Whether do you...` 或误用 `If you like it or not`（如真题（四）第49题 A、D） | 表“无论是否”的让步状语从句只能用 `whether … or not`（严禁用 `if`），且从句内部一律保持**陈述语序** |
| **代动词词类与时态错配** | 前句谓语是实义动词却填非谓语 `doing/done` 或错用过去时 `did`（如完形真题（五）第57题 A、B、C），或前句是 `be` 却用 `do` 替代 | 遵循两步法：① 看前文被替谓语定词类（实义动词用 `do`、系动词/被动用 `be`、完成时用 `have`、情态动词重复自身）；② 看当前分句的主语和时间定单复数与时态 |
| **`do` 与 `do so` 混用** | 需要替代“实义动词 + 宾语/状语”整块动宾结构时漏掉 `so`，或误写成倒装 `so did` | 同一主语顺承前文“做了某事（含宾语）”时用 `did so`；换用另一主语表“某人也如此”时才用倒装 `so did sb.` |
| **`rather than / than` 后误加 `to`** | 在 `would rather do A than …` 或 `prefer to do A rather than …` 的 `than` 后误选 `to do` 或 `doing`（如真题（二）第41题 B、C） | 凡与 `would rather` 或 `prefer to do` 配对的 `than / rather than`，其后动词一律省去 `to` 用**动词原形** |
| **省略不定式时漏掉符号 `to`** | 宾语位置省略重复不定式动词时，在 `want / hope / expect / ask / refuse / used / ought / be able` 后漏写 `to` | 上述词后省略重复动作时，必须保留不定式符号 `to` 作句尾代形式（如 `He didn't want to.`） |
| **平行结构形态失衡与混搭** | 写出 `*not only sings but also dancing` 或把 `prefer A to B` 与 `prefer to do A rather than do B` 混搭成 `*prefer reading than watching` | 用“对称性检验法”：并列连词两边词性与语法形式必须全等；严格区分 `prefer doing A to doing B` 与 `prefer to do A rather than do B` |
| **部分否定与全部否定混淆** | 把 `All the students didn't pass.` 误读为“全都没及格”，或写出错误语序 `*All not of the students` | `all / both / every + not` 恒为**部分否定**（并非都），句首标准语序为 `Not all / Not both / Not every`；表“全都不”必须换用 `none / neither / no one / nothing` |
| **`none` 与 `neither` 数量范围混用** | 在 `of the two`（两者）前误选 `none/all`，或在谓语为单数 `is` 时误选 `both` | 先划定数量范围：两者全否用 `neither`（谓语单数），两者全肯用 `both`（谓语复数）；三者及以上全否用 `none`，全肯用 `all` |
| **双重否定算反句意** | 将 `no … other than`、`never … without`、`not uncommon` 当作单纯否定句理解（如真题（九）第34题） | 先清点句中否定词（含负向词缀 `un-/in-/dis-` 与准否定词 `hardly/seldom`）个数：两处否定叠加恒等于**肯定强调** |
| **否定转移句的从句与反意疑问句出错** | 在 `I don't think` 后的从句里重复加 `not`，或把反意疑问句写成 `*…, do I?` | `I/We don't think/believe/suppose` 后的宾语从句必须用**肯定形式**；其反意疑问句必须与**从句主谓**一致且用**肯定形式**（如 `I don't think he is right, is he?`） |
| **句首否定词不倒装或重复加 `not`** | 写出 `*By no means we should…` 或 `*By no means should we not…`（如真题（八）第47题 A、D） | 否定词冠首主句必用**部分倒装**；句首否定词已否定全句，倒装谓语严禁再加 `not` |

## 五、自测（举一反三）

1. He spends more money than ________ necessary.
   A. is　B. are　C. being　D. to be

2. He works as hard as he ________ five years ago.
   A. does　B. did　C. do　D. is

3. He promised to help us, and he ________.
   A. did so　B. does so　C. so did　D. so does

4. The climate of Kunming is milder than ________ of Harbin.
   A. one　B. it　C. that　D. those

5. I'd rather stay at home than ________ out in the rain.
   A. going　B. to go　C. go　D. went

6. Not only ________ well, but he also dances beautifully.
   A. he sings　B. does he sing　C. he does sing　D. sings he

7. ________ of the two answers is correct.
   A. Both　B. Neither　C. All　D. None

8. ________ of the students in the class passed the exam.
   A. All not　B. Not all　C. Not both　D. Neither

9. It is not ________ for him to be late; he is often late.
   A. common　B. uncommon　C. usual　D. often

10. I don't think he ________ able to finish the work on time.
    A. is　B. isn't　C. was not　D. weren't

**答案与解析**

1. **A**。① **定位题干信号**：比较级 `more money than` 后缺少比较从句的谓语动词，且后接表语形容词 `necessary`。② **套用核心规则**：根据规则 2.3，比较从句的主语（“他所花的钱数”，视为抽象单数量）与前文重复而被省略，`than` 兼作从句主语，谓语必须用单数限定系动词 `is`（完整还原为 `more money than the amount that is necessary`）。③ **得出唯一答案**：故选 A。
2. **B**。① **定位题干信号**：同级比较结构 `as hard as` 的第二个 `as` 引导比较状语从句，从句主语为 `he`，句末有明确过去时间状语 `five years ago`。② **套用核心规则**：根据规则 2.3 与 2.6，替代主句实义动词 `works` 须用代动词 `do`，且代动词的时态必须由从句自身的时间状语 `five years ago` 决定，故用一般过去时 `did`。③ **得出唯一答案**：故选 B。
3. **A**。① **定位题干信号**：并列连词 `and` 连接后一分句，主语仍为同一人 `he`，需替代前文的不定式动宾短语 `help us`，且主句谓语 `promised` 为一般过去时。② **套用核心规则**：根据规则 2.6，替代“实义动词 + 宾语”整块结构且主语保持不变时，须用 `do so` 的过去式 `did so`（`so did` 为倒装结构，要求主语置于 `did` 之后表另一人“也如此”）。③ **得出唯一答案**：故选 A。
4. **C**。① **定位题干信号**：比较连词 `than` 后带后置定语 `of Harbin`，用于替代前文中心名词 `The climate`（单数/不可数概念）。② **套用核心规则**：根据规则 2.7，特指替代带后置定语的单数或不可数名词时，必须使用指示代词 `that`（`that of Harbin` = `the climate of Harbin`；`one` 仅替代可数名词单数泛指，`it` 指同一事物而非同类对比，`those` 用于复数）。③ **得出唯一答案**：故选 C。
5. **C**。① **定位题干信号**：句首有 `I'd rather stay`，后接比较连词 `than`。② **套用核心规则**：根据规则 2.8，`would rather do A than do B` 要求 `than` 前后必须对称使用**不带 `to` 的动词原形**，与 `stay` 对称的形式为原形 `go`。③ **得出唯一答案**：故选 C。
6. **B**。① **定位题干信号**：关联并列连词 `Not only` 置于句首，后一分句谓语 `dances` 为一般现在时第三人称单数。② **套用核心规则**：根据规则 2.8 与 2.11，`Not only` 置于句首时，其所在的第一个分句必须采用**部分倒装**（借用一般现在时第三人称单数助动词 `does` 提至主语 `he` 之前，实义动词还原为原形 `sing`）。③ **得出唯一答案**：故选 B。
7. **B**。① **定位题干信号**：空格后有明确表示“两者范围”的介词短语 `of the two answers`，且主句谓语动词为单数 `is`。② **套用核心规则**：根据规则 2.9，C 项 `All` 与 D 项 `None` 仅用于三者及以上，直接排除；A 项 `Both`（两者都）作主语时谓语必须用复数 `are`；唯有 `Neither` 表示“两者都不”且可搭配单数谓语 `is`。③ **得出唯一答案**：故选 B。
8. **B**。① **定位题干信号**：介词短语 `of the students in the class` 表明范围为“全班学生（三者及以上）”。② **套用核心规则**：根据规则 2.9，全称词 `all` 与 `not` 连用构成部分否定“并非所有学生都……”，且位于句首加 `of` 短语时，标准语序必须将 `Not` 置于 `all` 之前写作 `Not all of the students`（严禁写 `*All not of...`；C、D 仅用于两者）。③ **得出唯一答案**：故选 B。
9. **B**。① **定位题干信号**：分号后分句 `he is often late`（他经常迟到）解释了前分句的真实语义，而前分句已有否定词 `It is not ________`。② **套用核心规则**：根据规则 2.9，要使含 `not` 的前分句表达“他迟到是常有的事”，空格处必须填入带否定前缀的形容词 `uncommon`（不罕见的），与 `not` 构成**双重否定** `not uncommon`（= `very common`，司空见惯）。③ **得出唯一答案**：故选 B。
10. **A**。① **定位题干信号**：主句为第一人称看法类否定结构 `I don't think`，后接宾语从句 `he ________ able to finish the work on time`。② **套用核心规则**：根据规则 2.10，第一人称 `I/We` + 一般现在时 `think` 发生否定转移，否定词 `don't` 已移至主句，宾语从句内部必须采用**肯定形式**且时态与主句一致用一般现在时 `is`（若再选否定项 B/C/D 则变成双重否定，句意相反）。③ **得出唯一答案**：故选 A。
