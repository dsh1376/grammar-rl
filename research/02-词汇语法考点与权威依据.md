## 三、词汇题的五种命题方式（附本仓库对应文档）

| 命题方式 | 考查机制说明 | 本仓库题量与对应文档 |
| --- | --- | --- |
| 近义实词辨析 | 四个选项词性相同、语义相近，依靠题干宾语类型、主语特征或介词框架锁定唯一答案 | 动词 26 题（`14`）+ 名词 17 题（`12`）+ 形容词/副词 20 题（`13`） |
| 形近派生词与分词形容词辨析 | 同一词根的不同派生词（如 `effective / affected / efficient / sufficient`）或 `-ing / -ed` 分词形容词（如 `interested / interesting / disinterested`） | 详见 `知识点-词汇语法/18-构词法与词形变化.md` |
| 固定搭配与习语 | 考查 `介词 + 名词 + 介词`、`动词 + 名词 + 介词` 等不可拆改的固定组合 | 28 题 → `知识点-词汇语法/16-固定搭配与习语.md` |
| 短语动词辨析 | 同一核心动词（如 `put / take / make / look / bring`）搭配不同小品词后的词义分化 | 26 题 → `知识点-词汇语法/15-短语动词.md` |
| 场景惯用搭配 | 由特定语境同现词直接锁定固定复合词或习语（如 `stage fright` 怯场、`narrow escape` 九死一生） | 分散收录于 `12-名词词义辨析.md` 与 `13-形容词与副词.md` |
